    Gestión de Ficheros- Parte 2

    1. Introducción

    En la primera parte aprendimos a leer y escribir dentro de los ficheros (open, with). Pero, ¿qué pasa si queremos:

    • Saber si un fichero existe antes de intentar leerlo?
    • Listar todos los ficheros de una carpeta?
    • Crear un directorio para guardar logs?
    • Borrar un fichero temporal?
    • Ejecutar un comando del sistema como ping o ipconfig?

    Para todo esto se utiliza el módulo os que es la navaja suiza de Python para interactuar con el Sistema Operativo (Windows, Linux, Mac...).

    Paso inicial: Importar el módulo

    Siempre que quieras usar estas funciones, tu script debe empezar con:

    import os

    2. Comprobar existencia

    Es recomendable comprobar si un fichero existe antes de intentar lerlo. Para eso dispone de la función os.path.exists("ruta")

    Esta función:

    • Comprueba si una ruta (fichero o directorio) existe.
    • Devuelve True (si existe) o False (si no existe).

    import os

FICHERO = "config.ini"

# 1. Comprobamos ANTES de abrir
if os.path.exists(FICHERO):
    # Si entra aquí, es seguro abrirlo en modo 'r'
    print(f"Éxito: El fichero '{FICHERO}' existe.")
    with open(FICHERO, "r") as f:
        print("Contenido:")
        print(f.read())
else:
    print(f"Error: El fichero '{FICHERO}' no se ha encontrado.")

    Práctica Guiada

    1. Ejecuta este script. Si tienes el config.ini de la lección anterior, dirá «Éxito».
    2. Renombra tu fichero config.ini a config_viejo.ini.
    3. Vuelve a ejecutar el script. Verás cómo ahora te da el mensaje de «Error» en lugar de «romperse» (FileNotFoundError).

    3. Fichero o Directorio

    Para distinguir si un ruta es fichero o directorio se usan:

    • os.path.isfile("ruta"): Devuelve True solo si es un fichero.
    • os.path.isdir("ruta"): Devuelve True solo si es un directorio (carpeta).

    Este script indica si la ruta es fichero o directorio.

    import os

# Prueba a cambiar esto por "config.ini" o una carpeta que tengas
RUTA_A_PROBAR = input("Escribe un nombre de fichero o carpeta: ")

if not os.path.exists(RUTA_A_PROBAR):
    print(f"Error: '{RUTA_A_PROBAR}' NO existe.")
elif os.path.isfile(RUTA_A_PROBAR):
    print(f"Info: '{RUTA_A_PROBAR}' es un FICHERO.")
elif os.path.isdir(RUTA_A_PROBAR):
    print(f"Info: '{RUTA_A_PROBAR}' es un DIRECTORIO.")
else:
    print(f"Info: '{RUTA_A_PROBAR}' existe, pero no es ni fichero ni dir.")

    4. Listando: os.listdir()

    Como administrador de sistemas a menudo necesita procesar todos los ficheros de una carpeta (pe. buscar en todos los ficheros con extensión .log).

    Para eso dispone de os.listdir()

    • Función: os.listdir("ruta_del_directorio")
    • ¿Qué hace?: Lee un directorio.
    • Devuelve: Una lista de Python con los nombres (strings) de todo lo que hay dentro.

    import os

# El '.' significa 'esta misma carpeta donde se ejecuta el script'
RUTA = "."
# RUTA = input("Escribe un nombre de carpeta: ")

print(f"Contenido de la carpeta '{RUTA}':")

try:
    lista_de_ficheros = os.listdir(RUTA)
    print(type(lista_de_ficheros), lista_de_ficheros)
    # lista_de_ficheros.sort()s

    for nombre_fichero in lista_de_ficheros:
        print(f"- {nombre_fichero}")

except FileNotFoundError:
    print(f"Error: El directorio '{RUTA}' no existe.")
except NotADirectoryError:
    print(f"Error: '{RUTA}' es un fichero, no un directorio.")

    import os

RUTA = "."
print(f"Buscando ficheros .txt en '{RUTA}'...")
num_txt = 0

for nombre_fichero in os.listdir(RUTA):

    # os.listdir() devuelve el nombre de cada elemento del directorio.
    # Con os.path.join() construimos su ruta completa para poder
    # realizar operaciones sobre él.
    ruta_completa = os.path.join(RUTA, nombre_fichero)

    # Condición 1: ¿Es un fichero?
    # Condición 2: ¿Termina en ".txt"?
    if os.path.isfile(ruta_completa) and nombre_fichero.endswith(".txt"):
        print(f" -> Encontrado: {nombre_fichero}")
        num_txt += 1

print(f"\nTotal de ficheros .txt encontrados: {num_txt}")

    os.path.join

    Se utiliza os.path.join(RUTA, nombre_fichero) para la ruta con el nombre del fichero de forma segura. Podría pensar en utilizar 

    ruta_completa = RUTA + "/" + nombre_fichero
    pero no es recomendable. os.path.join() se encarga de utilizar correctamente el separador de directorios del sistema operativo y evita tener que preocuparte por las barras o contrabarras.

    Otra forma: usando pathlib

    pathlibes una forma más moderna y legible de trabajar con rutas y ficheros en Python. En lugar de tratar las rutas como simples cadenas de texto, las representa mediante objetos Path. En este caso cada ruta no es un str, sino un objeto Path y se pueden utilizar métodos como .is_file(), .is_dir() o propiedades como .name o .suffix

    from pathlib import Path

RUTA = Path(".")

for ruta in RUTA.iterdir():
    if ruta.is_file() and ruta.suffix == ".txt":
        print(ruta.name)

    5. Crear, borrar, mover

    • os.mkdir("nombre_carpeta"): Crea un nuevo directorio.
    • os.remove("nombre_fichero"): Borra un fichero permanentemente (¡no va a la papelera!).
    • os.rename("nombre_antiguo", "nombre_nuevo"): Renombra o mueve un fichero.

    Para mostrar el uso de estas funciones vea este script que busca ficheros .log y los mueve a una carpeta logs/.

    import os

CARPETA_LOGS = "logs"
RUTA_ACTUAL = "."

# 1. Crear la carpeta 'logs' si no existe
if not os.path.exists(CARPETA_LOGS):
    print(f"Creando carpeta '{CARPETA_LOGS}'...")
    os.mkdir(CARPETA_LOGS)
else:
    print(f"La carpeta '{CARPETA_LOGS}' ya existe.")

# 2. Buscar ficheros .log y moverlos
print("Buscando ficheros .log para mover...")
for nombre_fichero in os.listdir(RUTA_ACTUAL):

    # Comprobamos que sea un fichero y termine en .log
    ruta_antigua = nombre_fichero
    if os.path.isfile(ruta_antigua) and nombre_fichero.endswith(".log"):

        ruta_nueva = os.path.join(CARPETA_LOGS, nombre_fichero)
        try:
            os.rename(ruta_antigua, ruta_nueva)
            print(f" -> Moviendo '{ruta_antigua}' a '{ruta_nueva}'")

        except Exception as e:
            print(f"Error moviendo '{nombre_fichero}': {e}")

print("Organización completada.")

    6. Ejecutar comandos del Sistema:

    Para ejecutar un comando del sistema se utiliza subprocess.run(). Recibe el comando a ejecutar y sus argumentos como una lista.

    Por ejemplo, en el caso de querer ejecutar un ping:

    import subprocess

res = subprocess.run(["ping", "-c", "4", "8.8.4.4"])

# saber si el comando terminó correctamente
if res.returncode == 0:
    print("El host responde")
else:
    print("No se ha podido contactar con el host")

    Incluso puede capturar la salida del comando añadiendo las opciones capture_output y text y mostrado el resultado con .stdout

    res = subprocess.run(
    ["ping", "-c", "4", "8.8.4.4"],
    capture_output=True,
    text=True
)

print(res.stdout)

    import os
import subprocess

IP = "8.8.8.8"  # DNS de Google

print(f"Haciendo ping a {IP}...")

# os.name nos dice el S.O. ('nt' es Windows, 'posix' es Linux/Mac)
if os.name == "nt":
    # -n 4 -> 4 pings en Windows
    comando = ["ping", "-n", "4", IP]
else:
    # -c 4 -> 4 pings en Linux/Mac
    comando = ["ping", "-c", "4", IP]

resultado = subprocess.run(comando)

if resultado.returncode == 0:
    print("Ping finalizado correctamente.")
else:
    print("El ping ha finalizado con errores.")

    7. Ejercicios Propuestos

    Usa las técnicas aprendidas para resolver los siguientes ejercicios.

    Ejercicio 1: Limpiador de temp/

    • Crea una carpeta temp/.
    • Crea un script que pida al usuario un nombre de fichero (ej. fichero1.txt).
    • El script debe crear ese fichero dentro de temp/ con el contenido «fichero temporal». (Pista: usa os.path.join()).
    • Añade una segunda función: si el usuario escribe "limpiar", el script debe borrar todos los ficheros dentro de temp/. (Pista: usa os.listdir() y os.remove()).

    Ejercicio 2: Inventario de Red (Ping)

    • Crea un fichero ips.txt que contenga 3 IPs (ej. 8.8.8.8, 1.1.1.1, 192.168.1.254).
    • Escribe un script que lea ips.txt (con with open... y bucle for).
    • Para cada IP leída (recuerda usar .strip()), ejecuta un ping (con os.system()).

    Ejercicio 3: Auditor de config.ini. Combina todo. Escribe un script que:

    1. Compruebe si config.ini existe (con os.path.exists()).
    2. Si no existe, debe crearlo (con open en modo 'w') y escribir status=incompleto.
    3. Si existe, debe leerlo (con open en modo 'r') y comprobar si la palabra 'admin' está en el contenido.
    4. Debe imprimir Configuración OK o Configuración NO SEGURA (contiene 'admin').
