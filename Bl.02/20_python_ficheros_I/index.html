    Gestión de Ficheros - Parte I

    1. Introducción

    Hasta ahora toda la información que se utilizaba (variables, listas, diccionarios) se almacenaba en la memoria RAM. La RAM es volátil, lo que significa que cuando tu script de Python termina, toda esa información se borra.

    Como administradores de sistemas esto no es suficiente. Necesita por ejemplo:

    • Leer ficheros de configuración (ej: /etc/ssh/sshd_config).
    • Escribir en ficheros de log (ej: access.log).
    • Guardar una lista de IPs baneadas (ej: ips_bloqueadas.txt).

    Para esto necesita trabajar con almacenamiento persistente (el disco duro). Los ficheros son la forma en que guardamos datos de forma permanente. Otra posibilidad serán las bases de datos.

    2. Abrir el fichero: open()

    Para interactuar con un fichero Python necesita «abrirlo» para poder acceder al contenido. La función principal para esto es open().

    Su sintaxis básica es:

    descriptor_fichero = open("ruta_del_fichero", "modo")
    • "ruta_del_fichero": Es un string con el nombre y la ruta del fichero.
    • Ej: "hosts.txt" (si está en la misma carpeta).
    • Ej: C:\Logs\mi_log.txt (en Windows).
    • Ej: "/var/log/syslog" (en Linux).
    • "modo": Es un string que le indica a Python qué queremos hacer: leer, escribir o añadir.

    Los modos de apertura se resumen en esta tabla:

    Cuadro 1: Modos de apertura de ficheros

    Modo Significado ¿Qué hace? Si no existe... Si sí existe...
    'r' Read (Leer) Abre para leer. ¡Error! Lee desde el principio.
    'w' Write (Escribir) Abre para escribir. Lo crea nuevo. ¡Peligro! Lo borra todo.
    'a' Append (Añadir) Abre para añadir. Lo crea nuevo. No borra nada. Escribe al final.

    Tenga en cuenta que:

    • 'r' es el modo por defecto. fd = open("hosts.txt") es igual que fd = open("hosts.txt", "r").
    • 'w' es útil para crear nuevos informes, pero tenga en cuenta que borra el contenido previo.
    • 'a' es un modo más seguro para escribir, y se utiliza por ejemplo em ficheros de log.

    3. Trabajar con ficheros

    El proceso siempre tiene 3 pasos: Abrir, Operar, Cerrar.

    # 1. Abrir: fichero 'config.ini' en modo escritura ('w').
# Si ya existía, se borra su contenido. Si no, se crea.
print("Abriendo 'config.ini' en modo 'w'...")
fichero = open("config.ini", "w")

# 2. Operar: Escribe líneas en el fichero.
print("Escribiendo datos...")
fichero.write("hostname=servidor-web-01\n")
fichero.write("ip=192.168.1.100\n")
fichero.write("admin=root\n")
# '\n' es nueva línea.


# 3. Cerrar: guarda los cambios y libera el fichero.
fichero.close()
print("Fichero 'config.ini' creado y cerrado.")

# El *cursor* se pone al final del fichero.
print("Abriendo 'config.ini' en modo 'a'...")
fichero = open("config.ini", "a")

# 2. Operar: Escribe la nueva línea.
fichero.write("puerto=80\n")

# 3. Cerrar:
fichero.close()
print("Fichero modificado y cerrado.")

    4. Forma Segura: with open()

    En los ejemplos previos es fácil olvidar fichero.close(). Esto puede corromper datos o dejar ficheros «bloqueados».

    La solución en Python es utilizar el bloque with open(FICHERO, modo) as f:.

    with open("ruta_del_fichero", "modo") as mi_variable:
    #
    # Todo el código que usa el fichero va INDENTADO aquí.
    # No necesita llamar a .close()
    pass

# Aquí, fuera del bloque, Python ha cerrado ya el fichero
# automáticamente, incluso si ha ocurrido un error.
    Esta es la forma recomendada de trabajar con ficheros. Se reescribe el ejemplo anterior:

    FICHERO = "config.ini"

print(f"Abriendo {FICHERO} con 'with'...")

try:
    with open(FICHERO, "r") as f:
        # f es la variable que maneja el fichero
        contenido = f.read()

    # En este punto, el fichero YA ESTÁ CERRADO.
    print("Lectura completada (fichero cerrado automáticamente).")

    print("\n--- INICIO DEL FICHERO ---")
    print(contenido)
    print("--- FIN DEL FICHERO ---")

except FileNotFoundError:
    # Esto se ejecuta si open() falla porque el fichero no existe
    print(f"¡Error! El fichero '{FICHERO}' no existe.")

    5. Leer Ficheros línea a línea

    Si un fichero es un log de 2GB no puede usar .read(). Colapsaría la memoria RAM. Lo correcto es procesar el fichero línea por línea usando un bucle for.

    FICHERO = "config.ini"
print(f"Leyendo {FICHERO} línea por línea...")

try:
    with open(FICHERO, "r") as f:
        # 'f' se comporta como una lista de líneas
        for linea in f:
            # La variable 'linea' contiene una línea entera,
            # incluyendo el '\n' del final.

            # .strip() es un método de string que limpia
            # espacios, tabuladores y '\n' de los extremos.
            linea_limpia = linea.strip()

            # Imprimimos si la línea no está en blanco
            if linea_limpia:
                print(f"Línea leída: --> {linea_limpia} <--")

except FileNotFoundError:
    print(f"¡Error! El fichero '{FICHERO}' no existe.")

    6. Ejercicios Propuestos

    Usa las técnicas aprendidas (preferiblemente with open()) para resolver los siguientes ejercicios.

    1. Creador de Logs: script que pida al usuario su nombre y un mensaje. El script debe añadir (modo 'a') una línea al fichero mi_log.txt con el formato: [Nombre]: Mensaje. Si ejecutas el script 3 veces, el fichero debería tener 3 líneas.
    2. Lector de Configuración: Usando el fichero config.ini utilizado, escriba un script que lea el fichero línea por línea. Debe imprimir solo la línea que contiene la "ip".
    3. Contador de Líneas: Escribe un script que lea el fichero config.ini (o mi_log.txt si ya lo has creado). El script debe contar cuántas líneas tiene el fichero sin usar .read(). Al final, debe imprimir: El fichero tiene X líneas.
    4. Copiadora de Ficheros: script que lea todo el contenido de config.ini (con .read()) y luego escriba (con .write()) ese mismo contenido en un fichero nuevo llamado config_backup.ini.
