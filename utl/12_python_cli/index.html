    Introducción a Python: argumentos en línea de comandos

    Cuando ejecuta un programa desde la terminal puede pasarle argumentos para modificar su comportamiento sin tener que editar el código. Esta técnica es habitual en las herramientas de administración de sistemas Linux.

    Por ejemplo:

    $ ping -c 4 8.8.8.8
$ ls -l /var/log
$ python3 analizar.py --origen servidor1 --verbose

    En el último comando, analizar.py es el script, --origen es una opción que recibe el valor servidor1 y --verbose es un indicador que activa un comportamiento.

    1. Tipos de argumentos

    Considera este comando:

    $ python3 herramienta.py consultar --producto disco --verbose
    Elemento Tipo Descripción
    consultar Argumento posicional Normalmente se identifica por su posición y, salvo configuración adicional, es obligatorio.
    --producto disco Opción con valor Se reconoce por su nombre (--producto) y recibe el valor disco.
    --verbose Indicador o flag Basta con escribirlo para activar una funcionalidad. No necesita un valor a continuación.

    Aunque Python permite consultar los argumentos directamente mediante sys.argv, para scripts que necesitan varios argumentos resulta más cómodo utilizar argparse, un módulo de la biblioteca estándar que no requiere instalación adicional.

    ¿Argumentos o parámetros?

    En el uso cotidiano se emplean ambos términos. Y se usa opciones cuando lleven nombres como -p o --producto.

    2. Uso básico módulo argparse

    argparse permite declarar qué argumentos acepta un script y se ocupa de tareas habituales:

    • Comprobar si se han proporcionado los argumentos obligatorios.
    • Intentar convertir sus valores al tipo indicado (int, float, etc.).
    • Mostrar mensajes de error cuando los argumentos no cumplen esas condiciones.
    • Generar automáticamente una ayuda con -h o --help.

    Una limitación importante

    argparse no comprueba automáticamente todas las reglas del programa. Por ejemplo, puede verificar que una cantidad sea un entero, pero no que sea mayor que cero. Esa comprobación se debería hacer en la aplicación.

    2.1. Ejemplo: argumentos posicionales

    Se crea un script denominado uso_argparse.py, basado en una pequeña calculadora. Por ahora solo recibirá y mostrará los datos.

    uso_argparse.py
    import argparse

# Se crea el analizador de argumentos.
parser = argparse.ArgumentParser(
    description="Ejemplo de calculadora con argumentos posicionales."
)

# Se declaran tres argumentos posicionales.
parser.add_argument(
    "opera",
    help="Operación matemática: suma, resta, multiplica o divide."
)
parser.add_argument("num1", type=int, help="Primer operando entero.")
parser.add_argument("num2", type=int, help="Segundo operando entero.")

# Analiza lo que se ha escrito en la terminal.
args = parser.parse_args()

# Consulta de los argumentos mediante sus nombres.
print(f"Operación: {args.opera}")
print(f"Primer operando: {args.num1}")
print(f"Segundo operando: {args.num2}")

    Ejecutw el programa:

    $ python3 uso_argparse.py suma 10 5
Operación: suma
Primer operando: 10
Segundo operando: 5

    ¿Qué hace cada instrucción?

    1. argparse.ArgumentParser(...): crea el objeto que se encargará de analizar los argumentos. description añade una descripción a la ayuda.
    2. parser.add_argument(...): registra cada argumento admitido. Al no comenzar por -, estos tres argumentos son posicionales.
    3. type=int: solicita convertir el argumento a entero. Si la conversión falla, argparse muestra un error.
    4. parser.parse_args(): analiza los argumentos recibidos y devuelve un objeto de tipo Namespace.
    5. args.opera, args.num1 y args.num2: permiten acceder a los valores convertidos. No se trata de un diccionario, aunque sus atributos se consulten mediante nombres.

    ¿Es necesario indicar type=str?

    Si no se especifica type, argparse recibe el valor como una cadena de texto (str). P

    Puede comprobar la validación automática con estos ejemplos de ejecución y observe los mensajes de error que genera:

    $ python3 uso_argparse.py
$ python3 uso_argparse.py suma 10
$ python3 uso_argparse.py suma diez 5
$ python3 uso_argparse.py 10 5 suma
$ python3 uso_argparse.py suma 10 5 8

    Las situaciones anteriores muestran, respectivamente, argumentos obligatorios ausentes, falta de un operando, un entero no válido, un orden incorrecto y argumentos sobrantes.

    Por ejemplo, si falta el último argumento, aparecerá un mensaje similar al siguiente:

    usage: uso_argparse.py [-h] opera num1 num2
uso_argparse.py: error: the following arguments are required: num2

    Si se proporciona diez para num1, la conversión a int falla. Ante un error de uso, argparse muestra la explicación y, normalmente, termina el programa con código de salida 2.

    En Linux

    Para consultar el código de salida de la última orden ejecutada en Bash puedes utilizar echo $?. Comprueba la diferencia entre una ejecución correcta, --help y una ejecución con argumentos incorrectos.

    2.3. La ayuda --help

    La opción -h (equivalente a --help) se crea por defecto:

    $ python3 uso_argparse.py --help

    La ayuda presenta el uso del comando, la descripción del programa, los argumentos posicionales y sus explicaciones. La opción -h se muestra aunque no la hayamos declarado.

    3. Opciones y valores permitidos

    El siguiente ejemplo introduce novedades:

    • choices: restringe los valores admitidos para un argumento.
    • -p / --producto y -c / --cantidad: permiten identificar opciones por su nombre en lugar de por su posición.
    • --verbose para ilustrar un indicador booleano.
    gestion_inventario.py
    import argparse

parser = argparse.ArgumentParser(
    description="Ejemplo de recepción de argumentos para un inventario."
)

# Argumento posicional con un conjunto de valores admitidos.
parser.add_argument(
    "accion",
    choices=["agregar", "eliminar", "consultar", "listar"],
    help="Operación que se desea realizar."
)

# Opciones con nombre: forma corta y forma larga.
parser.add_argument(
    "-p", "--producto",
    help="Nombre del producto."
)
parser.add_argument(
    "-c", "--cantidad",
    type=int,
    help="Cantidad de unidades."
)

# Indicador booleano: no recibe un valor.
parser.add_argument(
    "-v", "--verbose",
    action="store_true",
    help="Muestra información adicional."
)

args = parser.parse_args()

print(f"Acción: {args.accion}")
print(f"Producto: {args.producto}")
print(f"Cantidad: {args.cantidad}")

if args.verbose:
    print("Modo detallado activado.")

    Ejemplos de invocaciones

    $ python3 gestion_inventario.py agregar --producto disco --cantidad 3
Acción: agregar
Producto: disco
Cantidad: 3

$ python3 gestion_inventario.py agregar -c 3 -p disco -v
Acción: agregar
Producto: disco
Cantidad: 3
Modo detallado activado.

$ python3 gestion_inventario.py listar
Acción: listar
Producto: None
Cantidad: None

    Observa que las opciones pueden utilizar su forma corta (-p) o larga (--producto) y que, en este ejemplo, pueden aparecer en distinto orden.

    Cuando se omite una opción que espera un valor, su valor predeterminado es None, salvo que indiquemos otra cosa. En cambio, args.verbose vale False cuando no aparece -v y True cuando sí aparece.

    Si se intenta ejecutar python3 gestion_inventario.py modificar, argparse rechazará la acción porque modificar no pertenece a la lista definida en choices.

    3.2. Argumentos opcionales y obligatorios

    Las opciones con nombre son opcionales por defecto. Podemos asignarles un valor predeterminado mediante default. Si modifica el código:

    parser.add_argument(
    "-c", "--cantidad",
    type=int,
    default=1,
    help="Cantidad de unidades (por defecto: 1)."
)

    También existe required=True para obligar a utilizar una opción, pero conviene reservarlo para los casos en que resulte necesario. Por ejemplo, la cantidad podría hacer falta para agregar, pero no para listar.

    3.3. Validaciones que debe programar

    Es necesario validar cuando los argumentos son válidos individualmente, pero no cumplen las condiciones de nuestra aplicación. 

    # se añade..
if args.accion == "agregar":
    if args.producto is None:
        parser.error("La acción 'agregar' requiere --producto.")

    if args.cantidad is None:
        parser.error("La acción 'agregar' requiere --cantidad.")

    if args.cantidad <= 0:
        parser.error("La cantidad debe ser mayor que cero.")

    parser.error(...) muestra un mensaje de uso y termina la ejecución con un error.
