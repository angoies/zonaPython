    Introducción a Python - Argumentos en CLI

    Uso módulo argparse

    Tiene más información sobre el uso de argparse en este enlace: https://noemioocc.github.io/posts/Ejecutar-script-python-con-argparse/

    Este módulo hace la comprobación del número de parámetros, el tipo, e incluso nos facilita mensajes de ayuda. Vea este ejemplo de su uso:

    # uso_argparse.py
import argparse

# Crea el objeto que almacenará los argumemtos
parser = argparse.ArgumentParser()

# Añade argumetos con nombre, tipo y ayuda
parser.add_argument('opera', type=str, help='operación matemática: suma|resta|multiplica|divide')
parser.add_argument('num1', type=int, help='primer operando')
parser.add_argument('num2', type=int, help='segundo operando')

# Analiza los argumentos
args = parser.parse_args()

# Acceso a los argumentos por su nombre
print(args.opera , args.num1, args.num2)

    Invoque el programa sin parámetros (o con un número incorrecto de ellos) y compruebe su funcionamiento:

    5.2.1. argparse con opciones

    # uso_argparse.py
import argparse

# Crea el objeto que almacenará los argumemtos
parser = argparse.ArgumentParser(description="Gestión inventario.")

# Espcificamos los argumentos que recibe con add_argument

# Con choice damos las valores permitidos , help la ayuda
parser.add_argument("accion", choices=["agregar", "eliminar", "consultar",
                    "listar"], help="Acción a realizar.")


# Parámetros "con nombre", pueden aparecer en cualquier orden 
# Se especifica el tipo
parser.add_argument("--producto", "-p", type=str, help="Nombre del producto.")
parser.add_argument("--cantidad", "-c", type=int, help="Cantidad del producto.")

args = parser.parse_args()

# Acceso a los argumentos a través de args
print(args.accion, args.producto, args.cantidad)
