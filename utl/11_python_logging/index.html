    Introducción a logging

    print() es útil durante el desarrollo, pero no es la herramienta adecuada para registrar permanentemente el funcionamiento de una aplicación.

    Python incluye:

    logging

    Ejemplo:

    import logging

logging.basicConfig(level=logging.DEBUG)

logging.debug("Inicio del programa")

numero = 10

logging.debug("numero=%s", numero)

    Salida aproximada:

    DEBUG:root:Inicio del programa
DEBUG:root:numero=10

    1. Niveles de logging

    Nivel Uso habitual
    DEBUG Información detallada para depuración
    INFO Funcionamiento normal
    WARNING Situación inesperada que permite continuar
    ERROR Error que afecta a una operación
    CRITICAL Error grave que puede impedir continuar

    Ejemplos:

    logging.debug("Valor de contador: %s", contador)
logging.info("Usuario autenticado correctamente")
logging.warning("Espacio en disco inferior al 10%%")
logging.error("No se pudo abrir el fichero")
logging.critical("No se puede conectar con la base de datos")

    2. Configurar logging

    import logging

logging.basicConfig(
    level=logging.DEBUG,
    format="%(levelname)s - %(message)s"
)

    Podemos incluir fecha y hora:

    logging.basicConfig(
    level=logging.DEBUG,
    format="%(asctime)s - %(levelname)s - %(message)s"
)

    3. Guardar logs en un fichero

    import logging

logging.basicConfig(
    filename="aplicacion.log",
    level=logging.DEBUG,
    format="%(asctime)s - %(levelname)s - %(message)s"
)

logging.info("Inicio del programa")

    En Linux podemos consultar el archivo con:

    cat aplicacion.log

    less aplicacion.log

    o seguirlo en tiempo real:

    tail -f aplicacion.log

    4. Logging dentro de funciones

    import logging

logging.basicConfig(
    level=logging.DEBUG,
    format="%(levelname)s - %(message)s"
)


def calcular_media(notas):
    logging.debug("Notas recibidas: %s", notas)

    suma = 0

    for nota in notas:
        logging.debug("Procesando nota=%s", nota)

        suma += nota

        logging.debug("Suma acumulada=%s", suma)

    media = suma / len(notas)

    logging.debug("Media calculada=%s", media)

    return media

    Los logs permiten reconstruir el comportamiento del programa.

    5. print() frente a logging

    Característica print() logging
    Fácil de usar Sí Sí
    Depuración rápida Sí Sí
    Niveles de importancia No Sí
    Guardar en fichero Manual Sí
    Fecha y hora Manual Sí
    Activar/desactivar mensajes Difícil Fácil
    Adecuado para aplicaciones reales No Sí

    6. Combinar logging y depurador

    Las dos herramientas se complementan.

    logging
   ↓
detectar una zona problemática
   ↓
breakpoint
   ↓
inspeccionar variables
   ↓
localizar la causa

    Ejemplo de estrategia

    Un mensaje WARNING indica que una determinada máquina está generando valores extraños.
    Después podemos reproducir el caso en VS Code y colocar un breakpoint justo antes del cálculo sospechoso.
