    Python y venv

    1. Necesidad de entornos virtuales

    Puede consultar detalles sobre entornos virtuales en este enlace: A Guide to Python's Virtual Environments

    Pero básicamente se pretende:

    • Poder trabajar con proyectos con distintas versiones de lenguaje de programación.
    • Poder tener en cada proyecto distintas versiones de los módulos que se importen.
    • Poder reproducir el entorno de trabajo en otro equipo a partir de un fichero de texto con los requisitos.
    • No añadir a la configuración global del equipo módulos que son específicos de cada proyecto.

    2. Paso 1: crear el entorno virtual

    Cree una carpeta para el proyecto y sitúese en ella:

    clases@d12:~$ mkdir proyecto
clases@d12:~$ cd proyecto/
clases@d12:~/proyecto$

    El comando para crear un entorno virtual en Python es

    python3 -m venv <nombre_directorio_entornovirtual>`

    Es habitual darle al directorio donde se almacena toda la información del entorno virtual siempre el mismo nombre, por ejemplo en este caso venv (o .venv).

    clases@d12:~/proyecto$ python3 -m venv venv
clases@d12:~/proyecto$ ls -l
total 4
drwxr-xr-x 5 clases clases 4096 dic  1 20:12 venv
clases@d12:~/proyecto$

    Warning

    Es posible que al intentar crear el entorno virtual le solicite instalar el módulo venv si no estuviese instalado.

    On Debian/Ubuntu systems, you need to install the python3-venv package using the following command: sudo apt install python3.11-venv

    Para ello:

    ```bash clases@d12:~/proyecto$ sudo apt install python3.11-venv [sudo] contraseña para clases: Leyendo lista de paquetes... Hecho Creando árbol de dependencias... Hecho Configurando python3.11-venv (3.11.2-6) clases@d12:~/proyecto$

    ```

    3. Paso 2: activar el entorno virtual

    Crear el entorno no implica que se esté usando. Para activarlo debe ejecutar este comando:

    clases@d12:~/proyecto$ source venv/bin/activate
(venv) clases@d12:~/proyecto$

    Warning

    Tenga en cuenta que la activación desde un entorno Windows es diferente: 

    c:\proyecto\>.venv\Scripts\activate

    Fuente: Setting up a Python virtual environment on Windows for absolute beginners

    3. Paso 3: Instalar un módulo

    En el siguiente ejemplo (que resuelve un sistema de ecuaciones) se usa el módulo numpy que no está instalado por defecto.

    El contenido del fichero main.py:

    import numpy as np

# solve(a, b) : Devuelve la solución del sistema de ecuaciones lineales
# con los coeficientes de la matriz a y los términos independientes 
# de la matriz b.
# Sistema de dos ecuaciones y dos incógnitas
# x + 2y = 1
# 3x + 5y = 2 

a = np.array([[1, 2], [3, 5]])
b = np.array([1, 2])

print(np.linalg.solve(a, b))
# Resultado [-1. 1.]

    Recién creado el entorno no debe haber ningún módulo instalado por el usuario. El comando pip freeze no muestra nada a la salida:

    (venv) clases@d12:~/proyecto$ pip freeze
(venv) clases@d12:~/proyecto$

    Si intenta ejecutat el script main.py da el error ModuleNotFoundError al no encontrar el módulo numpy:

    (venv) clases@d12:~/proyecto$ python3 main.py 
Traceback (most recent call last):
  File "/home/usuario/CIBER-PPS/bloque_03_programacion_segura/docs/tema_01_venv/src/numpy/main.py", line 14, in <module>
    import numpy as np
ModuleNotFoundError: No module named 'numpy'
(venv) clases@d12:~/proyecto$

    Instale el módulo numpy en el entorno virtual utilizando la herramienta pip:

    (venv) clases@d12:~/proyecto$ pip install numpy
Collecting numpy
...
Successfully installed numpy-2.2.0
(venv) clases@d12:~/proyecto$ pip freeze
numpy==2.2.0
(venv) clases@d12:~/proyecto$

    Ahora puede probar de nuevo el ejemplo. El resultado será similar a:

    (venv) clases@d12:~/proyecto$ python3 main.py
[-1. 1.]
(venv) clases@d12:~/proyecto$

    Compruebe ahora la salida del comando pip freeze. Observará que se ha instalado en el entorno virtual numpy (y todos aquellos otrso módulos que necesite).

    4. Paso 4: Salir del entorno

    Para salir del entorno se usa el comando deactivate:

    (venv) clases@d12:~/proyecto$ deactivate
clases@d12:~/proyecto$

    Puede intentar ejecutar el script anterior uan vez desactivado y observar que no funciona:

    clases@d12:~/proyecto$ python3 main.py
Traceback (most recent call last):
  File "/home/usuario/CIBER-PPS/bloque_03_programacion_segura/docs/tema_01_venv/src/numpy/main.py", line 1, in <module>
    import numpy as np
ModuleNotFoundError: No module named 'numpy'
clases@d12:~/proyecto$

    Si activa de nuevo el entorno se mantienen los módulos instalados previamente y puede ejecutar de nuevo el script, etc.

    clases@d12:~/proyecto$ source venv/bin/activate
(venv) clases@d12:~/proyecto$ python3 main.py
[-1. 1.]
(venv) clases@d12:~/proyecto$

    5. Uso de fichero de requisitos

    Si quiere almacenar los requisitos del proyecto puede generar un fichero con el listado de los módulos (y sus versiones) usando pip freeze y redirigir la salida a un fichero:

    (venv) clases@d12:~/proyecto$ pip freeze > requirements.txt
(venv) clases@d12:~/proyecto$

    Si quiere trabajar en otro equipo y recrear los mismos módulos basta, una vez creado y activado el nuevo entorno, ejecutar la instalación con pip de esos módulos a partir del fichero requirements.txt con la opción -r: 

    pip3 install -r requirements.txt

    clases@d12:~/proyecto-sedeA$ ls -a
requirements.txt
clases@d12:~/proyecto-sedeA$ python3 -m venv venv
clases@d12:~/proyecto-sedeA$ source venv/bin/activate
(venv) clases@d12:~/proyecto-sedeA$ pip freeze
(venv) clases@d12:~/proyecto-sedeA$ pip install -r requirements.txt
Collecting numpy==2.2.0
  Using cached numpy-2.2.0-cp311-cp311-manylinux_2_17_x86_64.manylinux2014_x86_64.whl (16.4 MB)
Installing collected packages: numpy
Successfully installed numpy-2.2.0
(venv) clases@d12:~/proyecto-sedeA$

    6. Borrar el entorno virtual

    Si desea borrar el entorno virtual basta con borrar el directorio venv creado dentro del proyecto:

    (venv) clases@d12:~/proyecto$ deactivate
clases@d12:~/proyecto$ rm -rf venv/
clases@d12:~/proyecto$

    7. Ejemplos de uso de entornos virtuales

    Note

    Depende del sistema operativo, módulos previamente instalados, etc puede que algunos de los módulos de estos ejemplos no necesiten instalación.

    7.1. FastAPI

    Puede ser que en algún momento trabaje con el framework de Python FastAPI. En ese caso necesita el módulo fastapi y adicionalmente un servidor de aplicaciones como uvicorn.

    En este ejemplo sencillo el fichero main.py contiene:

    from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}

    El proceso es similar al presentado previamente: crear un entorno virtual, iniciarlo 

    clases@d12:~$ mkdir app
clases@d12:~$ cd app
clases@d12:~/app$ python3 -m venv venv
clases@d12:~/app$ source venv/bin/activate
(venv) clases@d12:~/app$ nano main.py
(venv) clases@d12:~/app$

    e instalar los módulos. En este caso lso módulos necesarios son fastapi y uvicorn:

    (venv) clases@d12:~/app$ pip freeze
(venv) clases@d12:~/app$ pip install fastapi
Collecting fastapi
...
Successfully installed fastapi-0.104.1 idna-3.6
...
(venv) clases@d12:~/app$ pip install uvicorn
Collecting uvicorn
...
Installing collected packages: h11, click, uvicorn
Successfully installed click-8.1.7 h11-0.14.0 uvicorn-0.24.0.post1
(venv) clases@d12:~/app$
    Ya puede lanzar el servidor uvicorn con la aplicación. Observe la forma de invocarla:

    (venv) clases@d12:~/app$ uvicorn main:app --reload
INFO:     Will watch for changes in these directories: ['/home/clases/app']
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Started reloader process [3380] using StatReload
INFO:     Started server process [3382]
INFO:     Waiting for application startup.
INFO:     Application startup complete.

    Y ya puede acceder a la app en la URL http://127.0.0.1:8000 (o a http://127.0.0.1:8000/docs para ver la documentación de la API creada).

    clases@d12:~/app$ curl localhost:8000
{"message":"Hello World"}
clases@d12:~/app$ firefox localhost:8000 &

    7.2. módulo psutil

    Este es un ejemplo de uso del módulo psutil que permite obtener información el uso de los recursos del sistema.

    import psutil

print ( " --- Monitorizando el Sistema Local ---" )

# 1. Uso de CPU
# interval =1 significa que mide durante 1 segundo
cpu_uso = psutil.cpu_percent(interval=1)

print(f" Uso actual de CPU : { cpu_uso } %")

    Y el resultado esperado tras instalar el módulo:

    $ python3 cpu.py --- Monitorizando el Sistema Local --- Uso actual de CPU : 6.6 % $

    7.3. El módulo requests

    Veamos un ejemplo sencillo del uso de la biblioteca requests que permite enviar solicitudes HTTP (como GET, POST, PUT, DELETE) a servidores web de forma sencilla, legible y rápida.

    import requests

URL = "https://www.uca.es" # "https://www.uca.es/noexiste"
res = requests.get(URL)

print(res)
print(res.headers)
#print(res.text)

    El resultado será similar a:

    (venv) clases@d12:~/proyecto$ python prueba_request.py
<Response [200]>

    7.4. Jupyter Notebook

    Note

    Se incluye este ejemplo para que observe que la instalación puede generar mas de 90 dependencias y ocupar entre 250MB y varios GB en función de la instalación.

    En estos casos se ve la importancia de no compartir el entorno virtual y ern su lugar compartir el fichero de requisitos.

    Jupyter Notebook no es un "módulo" tradicional de Python en el sentido de una simple librería de funciones, sino un entorno web interactivo de desarrollo (IDE) de código abierto. Permite crear y compartir documentos web (archivos .ipynb) que combinan código ejecutable, ecuaciones matemáticas, visualizaciones y texto explicativo en un solo lugar.

    El proceso de trabajo es similar: crear un nuevo directorio, un entorno virtual, se activa y se instala el módulo notebook. Tiene más información sobre esta herramienta en https://jupyter.org/.

    En este ejemplo se mostrará Jupyter Notebook. También puede probar JupyterLab.

    Este ejemplo muestra que un módulo puede tener dependencias de otros y en este caso instala todos los necesarios (en este caso alrededor de 90):

    clases@d12:~$ mkdir notebook && cd notebook
clases@d12:~/notebook$ python3 -m venv venv
clases@d12:~/notebook$ source venv/bin/activate
(venv) clases@d12:~/notebook$ pip install notebook
Collecting notebook
...
clases@d12:~/notebook$ pip freeze | wc -l
90
(venv) clases@d12:~/notebook$
