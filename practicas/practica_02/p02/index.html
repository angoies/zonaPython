    Práctica: Control de catálogo

    1. Situación de partida

    Realizar una herramienta de consola para consultar y supervisar un catálogo de productos. La información no estará escrita dentro de tu programa: se obtendrá de una API REST pública llamada DummyJSON. A partir de los datos recuperados desarrollarás, paso a paso, un programa para listar productos, buscarlos, filtrarlos, calcular estadísticas, etc. La práctica repasa estructuras de control, listas, diccionarios, funciones y excepciones.

    novedades

    Se introducen únicamente dos novedades: la petición HTTP con requests y la conversión de JSON a estructuras Python mediante .json().

    1.1. Objetivos de aprendizaje

    Al terminar deberías poder:

    • Recorrer y transformar listas de diccionarios.
    • Acceder a diccionarios y listas anidados.
    • Diseñar funciones que reciben y devuelven estructuras de datos.
    • Validar datos y controlar excepciones.

    2. Preparación

    2.1. Requisito biblioteca requests

    Es posible que el módulo requests está ya instalado. Lo puede comprobar con esta secuencia:

    $ python3
Python 3.13.5 (main, Aug 10 2026, 12:06:59) [GCC 14.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> import requests
>>> quit()
$

    Si no desde terminal, preferiblemente en un entorno virtual:

    python3 -m venv venv
source venv/bin/activate
pip install requests

    2.2. Uso API dummyjson

    Comprueba primero en el navegador o con curl que esta dirección devuelve un documento JSON:

    https://dummyjson.com/products?limit=3

    El diccionario tiene una estructura parecida a esta (ejemplo abreviado):

    {
  "products": [
    {
      "id": 1,
      "title": "Producto de ejemplo",
      "category": "beauty",
      "price": 9.99,
      "stock": 5,
      "rating": 4.4,
      "tags": ["beauty", "mascara"],
      "dimensions": {"width": 23.17, "height": 14.43, "depth": 28.01},
      "reviews": [
        {"rating": 5, "reviewerName": "Cliente A", "comment": "Muy bien"},
        {"rating": 2, "reviewerName": "Cliente B", "comment": "Mejorable"}
      ]
    }
  ],
  "total": 194,
  "skip": 0,
  "limit": 30
}

    Observe que:

    • El diccionario tiene 4 campos, el primero es products
    • products es una lista de productos.
    • Cada producto es un diccionario.
    • Un producto contine entre otros
      • una lista: tags
      • un diccionario: dimensions
      • una lista de diccionarios: reviews
      • etc

    Si lo desea puede consultar la documentación oficial de productos.

    3. Apartados

    3.1. Apartado 1. Conexión con la API

    Se le proporciona esta función ya terminada, y otra que simula la consulta por si no funciona la API o no tiene acceso a internet.

    def obtener_productos
    def obtener_productos(limite=10):
    """Consulta DummyJSON y devuelve la lista 'products'.

    Propaga RequestException si falla HTTP o la conexión y ValueError si
    la respuesta no contiene la estructura esperada.
    """
    if not isinstance(limite, int) or isinstance(limite, bool) or limite <= 0:
        raise ValueError("El límite debe ser un entero positivo")

    respuesta = requests.get(
        URL_PRODUCTOS,
        params={"limit": limite},
        timeout=10,
    )
    respuesta.raise_for_status() #  Si servidor devuelve error lanza excepción HTTPError
    datos = respuesta.json()

    if not isinstance(datos, dict) or not isinstance(datos.get("products"), list):
        raise ValueError("Respuesta inesperada: falta la lista 'products'")

    return datos["products"]

    En ela puede observar que

    1. Realiza una petición GET a https://dummyjson.com/products utilizando requests.get(); envía limite como parámetro limit.
    2. Establece un tiempo de espera (timeout) de 10 segundos.
    3. Comprueba si la respuesta HTTP indica un error mediante raise_for_status().
    4. Convierte la respuesta JSON en estructuras Python mediante .json().
    5. Comprueba que la respuesta sea un diccionario que contenga la clave products y que su valor sea una lista. Si no lo es, lanza ValueError con un mensaje claro.
    6. Devuelve solo la lista de productos.

    3.2. Apartado 2. Listar productos

    Implementa:

    def mostrar_productos(productos):
    ...

    Muestra, para cada producto, su id, title, category, price y stock en una tabla de texto legible. Si recibes una lista vacía, muestra No hay productos que mostrar.

    Ejemplo de formato (valores ficticios):

     ID  PRODUCTO                         CATEGORÍA             PRECIO     STOCK
  1  Teclado USB                      accessories             25.90        8
  2  Monitor 24 pulgadas              electronics            159.00        3

    Puedes limitar visualmente la anchura del título sin cambiar su valor real en el diccionario.

    ??? tip "Pista: presentación" Utiliza un for y cadenas con formato (f"{valor:<20}", f"{precio:>8.2f}"). La función muestra datos; no necesita devolver ninguna lista nueva.

    3.3. Apartado 3. Buscar y filtrar

    Implementa dos funciones que devuelvan nuevas listas de referencias a productos; no imprimirán nada y no modificarán el catálogo:

    def buscar_por_titulo(productos, texto):
    ...

def filtrar_productos(productos, categoria=None, precio_max=None, solo_disponibles=False):
    ...

    Búsqueda: buscar_por_titulo devuelve productos cuyo título contiene el texto indicado, sin distinguir mayúsculas de minúsculas. Una cadena vacía puede devolver todos los productos.

    Filtros combinables: filtrar_productos permite seleccionar por categoría (coincidencia exacta, sin distinguir mayúsculas/minúsculas), precio máximo (incluido en el rango) y disponibilidad (stock > 0).

    Todos los filtros activos se combinan mediante una condición lógica Y.

    Ejemplo de uso:

    resultado = buscar_por_titulo(productos, "phone")
mostrar_productos(resultado)

resultado = filtrar_productos(
    productos,
    categoria="beauty",
    precio_max=30,
    solo_disponibles=True
)
mostrar_productos(resultado)

    No presupongas cuántos resultados habrá: los productos publicados en la API pueden cambiar.

    ??? tip "Pista: comparación de cadenas" Puedes utilizar .lower() (o.casefold()) y .strip() para normalizar texto. Construye una lista vacía, recorre los productos y añade con .append() los que cumplan todos los criterios aplicables.

    3.4. Apartado 4. Estadísticas

    Implementa:

    def calcular_estadisticas(productos):
    ...

    Debe devolver un diccionario con estas claves:

    Clave Contenido
    total Cantidad de productos analizados
    precio_medio Media aritmética de precios, redondeada a 2 decimales
    mas_caro Diccionario del producto de precio más alto (o None si no hay productos)
    unidades_en_stock Suma de las existencias de todos los productos
    por_categoria Diccionario categoría: número de productos

    La función debe funcionar con cualquier lista, también vacía. En ese caso devuelve cero para las cantidades y la media, None para mas_caro y {} para por_categoria.

    Después crea una pequeña función de presentación o muestra el resultado desde el menú. No introduzcas llamadas a la API en esta función.

    ??? tip "Pista: contar por categorías" Piensa en un diccionario que se inicializa vacío. Cada vez que aparece una categoría, aumenta su contador. Evita dividir entre cero cuando no hay productos.

    Ayuda Diccionarios: No olvide que si accede con notación de corchetes dicc[clave] con una clave que no existe se genera una excepción. En cambio con dicc.get(clave) si la clave no existe devuelve None, e incluso puede hacer que en vez de None devuelva un valor con dicc.get(clave, valor_si_no_existe). Vea un ejemplo en la consola de Python

    >>> test = {"clave1": "valor1", "clave2": "valor2" }
>>> test["clave3"]
Traceback (most recent call last):
File "<python-input-7>", line 1, in <module>
    test["clave3"]
    ~~~~^^^^^^^^^^
KeyError: 'clave3'
>>> res = test.get("clave3")
>>> print(res)
None
>>> res = test.get("clave3", "valor3")
>>> print(res)
valor3
>>>

    3.5. Apartado 5. Acceso a estructuras anidadas

    Implementa:

    def analizar_reviews(producto):
    ...

    analizar_reviews devuelve un diccionario con:

    • num_reviews: número de reviews del producto.
    • media_reviews: media de reviews[*]["rating"], redondeada a 2 decimales, o None si no hay reseñas.
    • positivas: cantidad de reseñas cuya puntuación es 4 o 5.
    def mostrar_ficha(producto):
    ...

    mostrar_ficha presenta el título, identificador, precio y existencias del producto, todas sus etiquetas (tags), las tres medidas (width, height, depth) de dimensions y el resumen calculado de reseñas.

    Diferencia importante

    El campo rating del producto no es lo mismo que la media que obtienes al recorrer reviews. El apartado pide calcular la segunda. Contempla el caso de un producto sin reseñas o sin dimensiones.

    ??? tip "Pista: accesos anidados" Para una lista anidada, primero obtén resenas = producto.get("reviews", []) y luego recórrela. Para un diccionario anidado, usa medidas = producto.get("dimensions", {}). Así podrás trabajar también con ejemplos incompletos.

    3.6. Apartado 6. Detectar incidencias

    Implementa:

    def generar_alertas(productos, umbral=5):
    ...

    Recorre el catálogo y devuelve una lista de diccionarios. Cada alerta debe tener al menos estas claves: id_producto, titulo, tipo y mensaje.

    Reglas:

    Situación Tipo de alerta
    stock == 0 AGOTADO
    0 < stock <= umbral STOCK_BAJO
    rating < 3.0 VALORACION_BAJA

    Para un mismo producto puede haber dos alertas distintas: una por stock y otra por valoración. No se genera STOCK_BAJO si el producto está agotado. El valor predeterminado del umbral es 5, pero la función debe admitir otros valores no negativos.

    alertas = generar_alertas(productos, umbral=5)
for alerta in alertas:
    print(alerta["tipo"], alerta["titulo"], alerta["mensaje"])

    ??? tip "Pista: reglas independientes" Para las dos reglas de stock utiliza if/elif. La valoración merece otro if porque puede coincidir con cualquiera de los estados de stock.
