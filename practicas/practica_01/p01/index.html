    Práctica Bloque 01

    Fichero con datos: servidores.py

    Apartado 1. Mostrar inventario

    Objetivo: recorrer una lista de diccionarios y mostrar resultados formateados.

    Implementa la función sugerida:

    def mostrar_inventario(servidores):
    """Muestra la información básica de los servidores recibidos."""

    Requisitos:

    1. Muestra, al menos, el ID, el nombre, el rol, el estado, el porcentaje de CPU y el de RAM.
    2. Recorre la lista recibida por parámetro: no accedas directamente a SERVIDORES dentro de esta función.
    3. Si la lista está vacía, muestra un mensaje explicativo en lugar de una tabla vacía.
    4. Utiliza f-strings para mejorar la presentación.
    5. La función también debe funcionar con una lista que contenga un solo equipo.

    Ejemplo de las dos primeras filas:

    ID    NOMBRE        ROL              ESTADO       CPU   RAM
------------------------------------------------------------
101   web-01        web              encendido     42%   55%
102   web-02        web              encendido     91%   82%
...

    Pista

    Puedes ajustar el ancho de columnas en una f-string. Ejemplo: 

    print(f"{'ID':<5} {'NOMBRE':<13} {'ROL':<16} )

    Apartado 2. Búsqueda

    Objetivo: usar bucles, condicionales, funciones y listas nuevas.

    Implementa estas funciones:

    def buscar_por_id(servidores, identificador):
    """Devuelve el diccionario correspondiente o None si no existe."""

    Requisitos:

    1. Buscar por ID debe devolver el servidor encontrado y None si no existe.
    2. Presenta las coincidencias reutilizando mostrar_inventario().

    Apartado 3. Filtrado

    Implementa esta función:

    def filtrar_por_estado(servidores, estado):
    """Devuelve una lista con los servidores del estado indicado."""

def filtrar_por_rol(servidores, rol):
    """Devuelve una lista con los servidores del rol indicado."""

    Requisitos:

    1. El filtro debe devolver una lista nueva y no deben borra datos del inventario original.
    2. Si no hay coincidencias, la lista resultante será [].
    3. Presenta las coincidencias reutilizando mostrar_inventario().

    Pista

    Una solución con for y append() es perfectamente válida. También puedes utilizar comprensiones de listas si ya las conoces y dominas.

    Apartado 4. Estadísticas

    Implementa:

    def calcular_resumen(servidores):
    """Devuelve un diccionario con las estadísticas globales."""


def mostrar_resumen(servidores):
    """Presenta las estadísticas de forma legible."""

    El diccionario que devuelve calcular_resumen() debe contener estas claves:

    Clave Cálculo
    total Número de servidores
    encendidos Número de servidores encendidos
    apagados Número de servidores apagados
    disponibilidad (encendidos / total) * 100

    Condición importante: si no hay servidores o ninguno está encendido, no debe producirse una división por cero. En tal caso, el indicador que no se pueda calcular tomará el valor 0.0 en esta práctica.

    Resultado esperado:

    Total: 8
Encendidos: 6
Apagados: 2
Disponibilidad: 75.00%

    Pista

    Puedes reutilizar filtrar_por_estado() para obtener los servidores encendidos. Separa calcular de mostrar para reutilizar los resultados.

    Apartado 5. Amplia Estadísticas

    Amplia las funciones :

    def calcular_resumen(servidores):
    """Devuelve un diccionario con las estadísticas globales."""


def mostrar_resumen(servidores):
    """Presenta las estadísticas de forma legible."""

    Para que el diccionario que devuelve calcular_resumen() añada a los valores anteriores el uso de cpu y RAM:

    Clave Cálculo
    total Número de servidores
    encendidos Número de servidores encendidos
    apagados Número de servidores apagados
    disponibilidad (encendidos / total) * 100
    cpu_media Media de CPU solo de servidores encendidos
    ram_media Media de RAM solo de servidores encendidos

    Condición importante: si no hay servidores o ninguno está encendido, no debe producirse una división por cero. En tal caso, el indicador que no se pueda calcular tomará el valor 0.0 en esta práctica.

    Resultado esperado:

    Total: 8
Encendidos: 6
Apagados: 2
Disponibilidad: 75.00%
CPU media (encendidos): 63.67%
RAM media (encendidos): 70.33%

    Pista

    Puedes reutilizar filtrar_por_estado() para obtener los servidores encendidos. Después, recórrelos acumulando cpu y ram.

    Apartado 6. diccionarios anidados

    Objetivo: trabajar con valores almacenados en diccionarios dentro de otros diccionarios.

    Implementa:

    def mostrar_servicios(servidor):
    """Muestra los servicios y su estado en un servidor."""

def mostrar_servicios_empresa(servidores):
    """Muestra los servicios y su estado de todos los servidores."""

def contar_servicios_inactivos(servidores):
    """Cuenta servicios inactivos en servidores encendidos.
       y lo devuelve comoo resultado"""

    Requisitos:

    1. Tenga en cuenta que los equipos tienen distintos programas instalados.
    2. Cuenta los servicios marcados como inactivo, pero solo si su servidor está encendido.

    Comprobación: inicialmente hay 2 servicios inactivos en servidores encendidos: rsync en backup-01 y ssh en monitor-01. El servicio mariadb de db-02 no se cuenta porque el servidor está apagado.

    Pista

    Recuerda que diccionario.items() devuelve pares clave-valor y diccionario.values() permite recorrer los valores.

    Apartado 7. Modificar Estados

    def cambiar_estado(servidores, identificador, nuevo_estado):
    """Simula un cambio entre 'encendido' y 'apagado'."""


def cambiar_servicio(servidores, identificador, nombre_servicio, nuevo_estado):
    """Simula un cambio entre 'activo' e 'inactivo'."""

    Cambiar el estado del servidor

    • Los únicos nuevos estados permitidos son encendido y apagado.
    • Si se recibe un estado distinto se genera una excepción del tipo ValueError("Estado de servidor no válido.")
    • Si el identificador no existe se genera una excepción del tipo ValueError("No existe un servidor con ese ID.")

    Cambiar el estado de un servicio

    • Solo se permiten servicios ya registrados en el equipo indicado.
    • Solo puede modificarse un servicio si su servidor está encendido.
    • Acepta exclusivamente activo o inactivo.
    • Rechaza IDs, nombres de servicio o estados incorrectos mediante ValueError.

    Manejar las excepciones

    Cuando se llame a las funciones anteriores debe usar try / except ValueError para informar del problema y seguir trabajando. Evite que una entrada incorrecta cierre toda la aplicación.

    Apartado 8. Menú e integración

    Objetivo: integrar las funciones creadas en un programa con interacción por teclado.

    Al terminar, el programa debe mostrar un menú equivalente a este:

    === CONSOLA DE INVENTARIO LINUX ===
1. Ver inventario
2. Buscar servidor por ID
3. Filtrar por rol
4. Resumen de la infraestructura
5. Ver servicios de un servidor
6. Cambiar estado de un servidor
7. Cambiar estado de un servicio
0. Salir
Elige una opción:

    Requisitos:

    1. Presenta el menú hasta que se elija 0.
    2. Cada opción llama a funciones de apartados anteriores: no dupliques su lógica dentro del menú.
    3. Informa de opciones desconocidas y de entradas inválidas; después, vuelve a mostrar el menú.
    4. El programa arranca desde un bloque if __name__ == "__main__":.
    5. Al salir recuerda que los cambios no se conservan tras reiniciar el script.
