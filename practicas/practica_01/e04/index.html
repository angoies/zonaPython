    Apartado 4. Estadísticas

    Implementa:

    def calcular_resumen(servidores):
    """Devuelve un diccionario con las estadísticas globales."""


def mostrar_resumen(servidores):
    """Presenta las estadísticas de forma legible."""

    El diccionario que devuelve calcular_resumen() debe contener estas claves:

    Clave Cálculo
    total Número de servidores
    encendidos Número de servidores encendidos
    apagados Número de servidores apagados
    disponibilidad (encendidos / total) * 100

    Condición importante: si no hay servidores o ninguno está encendido, no debe producirse una división por cero. En tal caso, el indicador que no se pueda calcular tomará el valor 0.0 en esta práctica.

    Resultado esperado:

    Total: 8
Encendidos: 6
Apagados: 2
Disponibilidad: 75.00%

    Pista

    Puedes reutilizar filtrar_por_estado() para obtener los servidores encendidos. Separa calcular de mostrar para reutilizar los resultados.
