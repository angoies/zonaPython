    Introducción a Python

    En estos ejemplos se presentan algunos de los elementos básicos que utilizaremos continuamente al programar en Python: variables, tipos de datos, cadenas de texto, valores booleanos y conversión de tipos.

    1. Entorno de trabajo

    • Sistema operativo Linux con Python ya instalado
    • Editor de texto Visual Studio Code
    • Trabajo en terminal

    2. Variables y tipos de datos

    Una variable permite guardar un valor para utilizarlo posteriormente. En Python no es necesario indicar de antemano el tipo de una variable: este se determina a partir del valor que le asignamos.

    2.1. Código completo

    # Variables, asignación (=) y tipos (int, float, str...) 

# Asignación
saldo_total = 254.55  # float
email = 'ana@local.com'  # str

print("saldo_total") # imprime cadena
print(saldo_total)   # imprime valor de la variable
  print(email)   # error indentación: el prograam se detiene

# Imprime tipo de las variables usando type(variable)
print("tipo de email: ", type(email)  )
print("tipo de saldo_total: ", type(saldo_total)  )
# print puede recibir varias expresiones separadas por comas

# Variables pueden cambiar de tipo
#  NO es algo recomdable
email = 4  # pasa de string a integer
print( "Tipo email: ", type(email)  )
print("El email es ", email, " y el saldo es ", saldo_total, "\n")

    2.2. Asignar valores a variables

    Las primeras instrucciones crean dos variables:

    saldo_total = 254.55
email = 'ana@local.com'

    saldo_total contiene un número decimal, por lo que su tipo es float. email contiene texto, por lo que su tipo es str.

    El símbolo = es el operador de asignación: guarda el valor situado a la derecha en la variable situada a la izquierda.

    Asignación y comparación no son lo mismo

    En Python, = se utiliza para asignar un valor. Más adelante veremos que == se utiliza para comparar dos valores.

    2.3. Imprimir texto o imprimir una variable

    Estas dos instrucciones parecen muy similares, pero no hacen lo mismo:

    print("saldo_total")
print(saldo_total)

    La primera imprime literalmente el texto:

    saldo_total

    La segunda consulta el contenido de la variable e imprime:

    254.55

    Las comillas son, por tanto, importantes: "saldo_total" es una cadena de texto, mientras que saldo_total es el nombre de una variable.

    2.4. Un error de indentación

    El ejemplo contiene intencionadamente esta línea:

      print(email)

    Hay espacios al comienzo de la línea sin que exista ningún bloque que justifique esa indentación. Python considera la indentación parte de la sintaxis y detendrá el programa con un IndentationError.

    Mientras ese error exista, las instrucciones posteriores no llegarán a ejecutarse.

    La línea correcta sería:

    print(email)

    La indentación importa

    En Python no utilizamos la indentación solo para que el programa quede más bonito. Sirve para indicar qué instrucciones pertenecen a determinados bloques de código.

    2.5. Consultar el tipo de un dato

    La función type() permite saber de qué tipo es un valor o una variable:

    print("tipo de email: ", type(email))
print("tipo de saldo_total: ", type(saldo_total))

    Una vez corregido el error anterior, veremos que inicialmente:

    • email es de tipo str.
    • saldo_total es de tipo float.

    Además, print() puede recibir varios valores separados por comas:

    print("El email es ", email, " y el saldo es ", saldo_total)

    2.6. Una variable puede cambiar de tipo

    Python permite hacer esto:

    email = 4

    Aunque antes email contenía una cadena, ahora contiene un entero (int).

    Es posible hacerlo, pero normalmente no es una buena práctica reutilizar una variable para almacenar información de naturaleza completamente diferente. El nombre email, además, deja de describir correctamente lo que contiene.

    2.7. Posibles mejoras

    • Corregir la indentación de print(email).
    • Evitar que una variable llamada email termine almacenando el número 4.
    • Utilizar nombres de variables que describan claramente su contenido.
    • Mantener un estilo uniforme en los espacios y llamadas a print().

    3. Trabajo con cadenas de texto

    Las cadenas (str) representan texto. Python proporciona muchas operaciones para mostrarlas, transformarlas, buscar contenido en ellas y recorrer sus caracteres.

    3.1. Código completo

    # Ejemplo uso format en print
nombre = "Alfredo Zumberg"
edad = 23
altura = 1.915
print(nombre, "su edad es", edad, "y altura", altura)
# Uso de format con cadenas
print(f"{nombre} su edad es {edad} y altura {altura:.1f}") 


# Algunos métodos de string

saludo = "Hola Mundo"
print("Valor de saludo:", saludo)

print("Resultado de saludo.lower():", saludo.lower())
print("Valor de saludo:", saludo)


# No modifica cadena original. 
# Si queremos modificar hace falta asignación
saludo = saludo.lower()
print("Valor de saludo:", saludo)

# Replace, lo mismo..
print('Resultado de saludo.replace("mundo", "universo"):' , saludo.replace("mundo", "universo"))
print("Valor de saludo:", saludo)

# el tipo str se puede tratar como array o lista:
saludo ="¡Hola mundo!"
print("Primer carácter:", saludo[0])
print("Segundo carácter:",saludo[1])
print("Longitud saludo:", len(saludo))

# Buscar en un str: in y not in
texto = "The best thiNgs  life are free!"
busca = "FREE"

if busca.lower() in texto.lower():
    print(f"{busca} sí está en {texto}")
else:
    print(f"{busca} NO está en {texto}")

# o en negativo y sin ser case sensitve
if busca not in texto:
    print(f"{busca} NO está en {texto}")
else:
    print(f"{busca} sí está en {texto}")


# Concatenar str
nombre = "Raquel"
apellidos = "García Ross"
print(nombre + " " + apellidos)  # el operador + con cadenas concatena

nombreCompleto = apellidos + ", " + nombre
print(nombreCompleto)

# Extraer parte del string: slice

# La sintaxis del slicing en Python es string[inicio:fin:paso]:
#   - inicio: Por defecto empieza desde el extremo del string.
#   - fin: Por defecto recorre hasta el otro extremo.
#   - paso: por defecto 1.

saludo = "Hola Mundo"
print(saludo[:4])  # "Hola"
print(saludo[5:])  # "Mundo"
print(saludo[::2]) # de dos en dos => "Hl ud"

# Para invertir una cadena se usa salto negativo
print(saludo[::-1]) # en order inverso => "odnuM aloH"



# Se muestra ahora el uso de cadenas con bucle for

nombre = "www.aulas.local"
# a) Recorrer cada caracter de un str
for x in nombre:
    print(x)

# b) Recorrer cada caracter de un str 
# usando el índice o posición 
# se introduce el uso de range()
for i in range(len(nombre)):
    print(f"{i}: {nombre[i]}")


# Ejemplo de ejecución de range
# >>> for i in range(5):
# ...     print(i)
# ...     
# 0
# 1
# 2
# 3
# 4
# >>>

    3.2. Mostrar valores con print() y f-strings

    Podemos imprimir varios valores separándolos mediante comas:

    print(nombre, "su edad es", edad, "y altura", altura)

    Otra posibilidad muy cómoda son las f-strings:

    print(f"{nombre} su edad es {edad} y altura {altura:.1f}")

    Todo lo que aparece entre {} se sustituye por su valor.

    En el caso de:

    {altura:.1f}

    se solicita mostrar el número decimal con una cifra después del punto decimal.

    3.3. Métodos de las cadenas

    Una cadena dispone de métodos que permiten obtener nuevas cadenas transformadas.

    Por ejemplo:

    saludo.lower()

    devuelve una versión en minúsculas.

    Es importante observar que:

    print(saludo.lower())
print(saludo)

    no modifica el contenido original de saludo.

    Para conservar el nuevo valor debemos asignarlo:

    saludo = saludo.lower()

    Algo parecido sucede con replace():

    saludo.replace("mundo", "universo")

    devuelve una cadena nueva en la que se ha realizado la sustitución, pero no modifica automáticamente saludo.

    Las cadenas son inmutables

    Una cadena no se modifica internamente. Operaciones como lower() o replace() producen una nueva cadena. Si queremos conservarla, tendremos que asignarla a una variable.

    3.4. Acceder a caracteres y obtener la longitud

    Podemos acceder a los caracteres de una cadena mediante su posición:

    saludo = "¡Hola mundo!"
print(saludo[0])
print(saludo[1])

    Las posiciones comienzan en 0:

    • saludo[0] es ¡.
    • saludo[1] es H.

    La función len() devuelve el número de caracteres:

    len(saludo)

    Aunque en el comentario original se compara un str con un array o una lista, es más preciso decir que una cadena es una secuencia de caracteres. Podemos acceder a sus posiciones de forma parecida a una lista, pero una cadena no se puede modificar carácter a carácter porque es inmutable.

    3.5. Buscar texto con in y not in

    El operador in permite comprobar si un texto aparece dentro de otro:

    if busca.lower() in texto.lower():

    En el ejemplo convertimos ambas cadenas a minúsculas antes de compararlas. De esta forma no importa que una aparezca como "FREE" y otra como "free".

    not in comprueba lo contrario:

    if busca not in texto:

    Atención al segundo ejemplo

    El comentario indica que esta segunda búsqueda tampoco distingue mayúsculas y minúsculas, pero el código sí las distingue, porque compara directamente busca con texto.

    Si quisiéramos una búsqueda negativa sin distinguir mayúsculas y minúsculas, podríamos escribir:

    if busca.lower() not in texto.lower():
    print(f"{busca} NO está en {texto}")

    3.6. Concatenar cadenas

    El operador + une cadenas:

    nombre = "Raquel"
apellidos = "García Ross"

print(nombre + " " + apellidos)

    También podemos construir y guardar una nueva cadena:

    nombreCompleto = apellidos + ", " + nombre

    El resultado sería:

    García Ross, Raquel

    3.7. Extraer partes de una cadena: slicing

    Python permite obtener fragmentos mediante la sintaxis:

    cadena[inicio:fin:paso]

    Por ejemplo:

    saludo = "Hola Mundo"

print(saludo[:4])
print(saludo[5:])
print(saludo[::2])
    • saludo[:4] toma desde el principio hasta la posición 4, sin incluirla.
    • saludo[5:] toma desde la posición 5 hasta el final.
    • saludo[::2] recorre la cadena de dos en dos.

    También podemos utilizar un paso negativo:

    saludo[::-1]

    Esto recorre la cadena en sentido contrario y permite invertirla.

    3.8. Recorrer una cadena con for

    Una cadena puede recorrerse carácter a carácter:

    for x in nombre:
    print(x)

    En cada vuelta del bucle, x contiene uno de los caracteres.

    También podemos recorrer las posiciones:

    for i in range(len(nombre)):
    print(f"{i}: {nombre[i]}")

    Aquí se combinan tres elementos:

    • len(nombre) obtiene la longitud.
    • range(...) genera las posiciones desde 0.
    • nombre[i] obtiene el carácter situado en cada posición.

    Por ejemplo:

    range(5)

    genera los valores:

    0
1
2
3
4

    El 5 no se incluye.

    3.9. Posibles mejoras

    • Utilizar nombres en estilo snake_case, por ejemplo nombre_completo en lugar de nombreCompleto.
    • Corregir el comentario de la segunda búsqueda con not in, ya que el código mostrado sí distingue mayúsculas y minúsculas.
    • Hablar de las cadenas como secuencias de caracteres en vez de considerarlas arrays o listas.
    • Cuando solo queremos recorrer los caracteres, for caracter in cadena es normalmente más sencillo que usar posiciones.

    4. Variables lógicas o booleanas

    El tipo bool representa valores lógicos. Solo existen dos:

    True
False

    4.1. Código completo

    # lógica o booleana
autorizado = False    # el otro valor posible True
print( type(autorizado)  )


# ejemplo de uso de vaiable lógica
if autorizado==True:  # autorizado==True <=> autorizado 
    print("Puede pasar")
    print("resto del bloque positivo")
else:
    print("No puede pasar")
    print("resto del bloque negativo")

    4.2. El tipo bool

    La variable:

    autorizado = False

    contiene un valor booleano.

    Podemos comprobar su tipo:

    print(type(autorizado))

    4.3. Utilizar un booleano en una condición

    El ejemplo utiliza:

    if autorizado == True:

    Si la condición es verdadera, se ejecutan las instrucciones indentadas debajo del if. En caso contrario, se ejecuta el bloque asociado a else.

    Como autorizado vale False, se ejecutará:

    print("No puede pasar")
print("resto del bloque negativo")

    La indentación indica qué instrucciones forman parte de cada bloque.

    4.4. Una forma más sencilla

    No es necesario comparar explícitamente un booleano con True.

    En lugar de:

    if autorizado == True:

    podemos escribir:

    if autorizado:

    Ambas formas expresan la misma condición, pero la segunda es más habitual y clara en Python.

    4.5. Posibles mejoras

    El ejemplo podría escribirse de forma más sencilla así:

    autorizado = False

if autorizado:
    print("Puede pasar")
    print("Resto del bloque positivo")
else:
    print("No puede pasar")
    print("Resto del bloque negativo")

    5. Conversión de tipos

    Los datos introducidos mediante input() se obtienen como cadenas de texto. Si queremos realizar operaciones numéricas con ellos, tendremos que convertirlos.

    5.1. Código completo

    # conversión de tipos

# Ejemplo sin cast que no "funciona"
saldo = input("saldo: ")
incremento = input("incremento: ")

total = saldo + incremento
print("Valor de total sin cast: ", total)
print(type(saldo))
print(type(incremento))
"""
 El operador + en cadenas concatena
"""

# Se intenta ahora haciendo cast de las cadenas
saldo = float(saldo)
incremento = float(incremento)
total = saldo + incremento
print("Valor de total: ", total)

"""
 => Convertir a números las lecturas antes de operar con ellas 
"""

    5.2. input() devuelve una cadena

    Estas instrucciones leen datos escritos por el usuario:

    saldo = input("saldo: ")
incremento = input("incremento: ")

    Aunque escribamos números, el resultado de input() es de tipo str.

    Por ejemplo, si escribimos:

    saldo: 100
incremento: 25

    internamente tendremos dos cadenas equivalentes a:

    saldo = "100"
incremento = "25"

    5.3. ¿Qué sucede al utilizar +?

    La operación:

    total = saldo + incremento

    no suma matemáticamente los valores. Como ambos son cadenas, + las concatena.

    Con los valores anteriores obtendríamos:

    10025

    en vez de:

    125

    Las llamadas a type() permiten comprobar el motivo:

    print(type(saldo))
print(type(incremento))

    5.4. Convertir a float

    Podemos convertir ambas cadenas a números decimales:

    saldo = float(saldo)
incremento = float(incremento)

    A partir de ese momento:

    total = saldo + incremento

    sí realiza una suma numérica.

    Este proceso de convertir un valor de un tipo a otro suele denominarse conversión de tipos o, habitualmente, casting.

    Una forma habitual

    Si sabemos desde el principio que necesitamos un número, también podemos convertir directamente el resultado de input():

    saldo = float(input("Saldo: "))
incremento = float(input("Incremento: "))

    5.5. ¿Y si el usuario no introduce un número?

    La conversión:

    float(saldo)

    solo funciona si el contenido puede interpretarse como un número.

    Por ejemplo, si el usuario introduce:

    hola

    Python producirá un ValueError.

    Más adelante podremos controlar este tipo de situaciones validando los datos introducidos o tratando las excepciones.
