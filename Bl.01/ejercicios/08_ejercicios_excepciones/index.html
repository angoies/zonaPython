    Ejercicios

    1. Ejercicio 1. Conversión a entero

    Pide al usuario un número entero.

    Si introduce un valor que no pueda convertirse con int(), muestra:

    Debe introducir un número entero

    2. Ejercicio 2. División

    Pide dos números enteros y divide el primero entre el segundo.

    Controla:

    • ValueError;
    • ZeroDivisionError.

    3. Ejercicio 3. Crear un directorio

    Pide al usuario el nombre de un directorio y créalo con:

    os.mkdir()

    Controla al menos:

    • FileExistsError;
    • PermissionError.

    Si se crea correctamente, muestra:

    Directorio creado

    4. Ejercicio 4. Acceso a una lista

    Partiendo de:

    servicios = ["ssh", "http", "https"]

    pide una posición y muestra el servicio correspondiente.

    Controla:

    • ValueError;
    • IndexError.

    5. Ejercicio 5. Diccionario de servidor

    Partiendo de:

    servidor = {
    "nombre": "web01",
    "ip": "192.168.1.20",
    "puerto": 80
}

    pide una clave al usuario e intenta mostrar su valor utilizando:

    servidor[clave]

    Controla KeyError.
