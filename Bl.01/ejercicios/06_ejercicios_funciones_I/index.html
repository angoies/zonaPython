    Ejercicios

    Ejercicio 1. Directorio actual

    Utiliza el módulo os para mostrar el directorio actual.

    Ejercicio 2. Contenido de /tmp

    Obtén el contenido de /tmp con os.listdir() y muestra cada elemento utilizando un for.

    Ejercicio 3. Crear directorio

    Pide al usuario un nombre y crea dentro de /tmp un directorio con ese nombre.

    Ejercicio 4. Renombrar un archivo

    Supón que existe /tmp/informe.txt. Utiliza os.rename() para renombrarlo como /tmp/informe.old.

    Ejercicio 5. Consultar ayuda

    Ejecuta:

    help(os.listdir)

    y localiza en la ayuda el parámetro que recibe y qué información devuelve.
