    Introducción a Python

    Ejercicios Bloque 01

    Tipos de datos

    1. Declara variables para almacenar el nombre de un alumno, el número de asignaturas, y la nota media de acceso. Imprime todas usando una única instrucción print. Imprime las nota media con dos decimales.
    2. Solicita dos números por teclado y calcula e imprime la media.

    Estructuras de control

    1. Solicita un valor entero por teclado. Imprime un mensaje indicando:
      • si es menor que cero
      • si es mayor que 10
      • si está entre 0 y 10
    2. Solicita una clave por teclado. Si el valor es "1234" imprime el mensaje "Clave no permitida"
    3. Solicita una clave por teclado. Si la longitud es menor de 10 imprime el mensaje "clave no permitida",
    4. Solicita el login y clave por teclado. Si el login está incluido en la clave "clave no permitida".
    5. Crear script que compruebe las 3 condiciones anteriores para dar por válida una clave
    6. Escribe un script que pregunte al usuario un numero de puerto (entero). Si el puerto es menor o igual a 1024, debe imprimir El puerto es ’Well-Known’ (Reservado). Si no, debe imprimir El puerto es ’Registered’ (Libre). Comprube que el puerto es valido (no negativo, y menor o igual a 65536.
    7. Imprimir los números del 1 al 10 separados por comas en una única línea.
    8. Solicitar un número por teclado e imprimir la tabla de multiplicar correspondiente.
    9. Bucles anidados: imprimir las tablas de multiplicar del 1 al 10.
    10. Solicita el login y clave por teclado. Si el login está incluido en la clave indicarlo y volver a solicitar la clave hasta que cumpla.
    11. script que pida al usuario numeros enteros y los suma. El bucle debe terminar cuando el usuario introduzca el numero 0, y en ese momento debe imprimir la suma total.

    Listas y diccionarios

    1. Dada una lista de valores de latencias (float) imprimir dicha lista y calcular la media.
    2. Solicitar una IP por teclado. Comprobar que no esté incluida en la lista bloqueados = ["10.10.10.100", "192.168.1.200", "8,8,8,8"].
    3. Solicitar por teclado un string con números de puertos separados por espacios. Crear a partir de esa entrada una lista de puertos.
    4. Dado el diccionario servicios = {"ssh": 22, "http":80, "ftp": 21} escriba un script que use un bucle for para imprimir solo los nombres de los servicios (las claves).
    5. Usando el mismo diccionario, escribe un script que use el metodo .items() para imprimir para cada servicio El servicio xxx usa el puerto yyy.

    Funciones

    1. Función que devuelve True si un número entero está entre 1 y 10, False en caso contrario.
    2. Función que solicita un número entero al usuario. Si el valor no está entre 1 y 10 solicita de nuevo el número. Devuelve como resultado de la función el número.

    3. Función que recibe como argumento login y clave. Devuelve True si la clave es correcta o False si no (longitud <10>, o login incluido en clave)

    4. Script que solicita al usuario una cadena con valores de temperatura numéricas y presenta un menú con las opciones

      • Calcular la media
      • Calcular el número días con temperaturas superiores a 40 grados
      • Calcular la máxima
      • Nuevas temperaturas
      • Salir
