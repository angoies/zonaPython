    Ejercicios

    Ejercicio 1. Crear un diccionario

    Crea un diccionario llamado servidor con estas claves:

    • "nombre"
    • "ip"
    • "puerto"

    Asigna valores de ejemplo y muestra el diccionario completo.

    Ejercicio 2. Consultar elementos

    Partiendo de:

    usuario = {
    "nombre": "Ana",
    "edad": 21,
    "activo": True
}

    muestra por separado:

    1. el nombre;
    2. la edad;
    3. si está activo.

    Ejercicio 3. Modificar y añadir información

    Partiendo del diccionario anterior:

    1. cambia la edad a 22;
    2. añade una clave "email";
    3. muestra el diccionario completo.

    Ejercicio 4. Buscar una clave

    Crea:

    equipo = {
    "hostname": "server01",
    "ip": "192.168.1.10",
    "so": "Linux"
}

    Pide al usuario el nombre de una clave.

    Comprueba si existe utilizando:

    in

    y muestra su valor si existe.

    Pista

    Puedes comprobar una clave así:

    if clave in equipo:

    Ejercicio 5. Recorrer clave y valor

    Recorre este diccionario:

    puertos = {
    "ssh": 22,
    "http": 80,
    "https": 443
}

    y muestra:

    ssh => 22
http => 80
https => 443

    Ejercicio 6. Utilizar get()

    Partiendo de:

    persona = {
    "nombre": "Luis",
    "ciudad": "Cádiz"
}

    consulta con get():

    • "nombre";
    • "telefono".

    Para "telefono", utiliza como valor por defecto:

    No disponible
