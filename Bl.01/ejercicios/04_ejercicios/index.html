    Ejercicios

    Ejercicio 1. Crear y consultar una lista

    Crea una lista con los puertos 22, 53, 80, 443 y 8080. Muestra la lista completa, el primer elemento, el último y el número de elementos.

    Ejercicio 2. Modificar una lista

    Partiendo de:

    usuarios = ["ana", "luis", "marta"]

    cambia "ana" por "alfredo", añade "raquel" al final e inserta "carlos" en la posición 1.

    Ejercicio 3. Buscar una IP

    Crea:

    ips = ["192.168.1.1", "10.0.0.1", "172.16.0.1"]

    Pide al usuario una IP y muestra si está o no en la lista utilizando in.

    Ejercicio 4. Posición de una IP

    Amplía el ejercicio anterior para mostrar también la posición cuando exista, evitando que se produzca ValueError.

    Ejercicio 5. Ordenar edades

    Crea:

    edades = [34, 18, 55, 21, 40]

    Ordénala de menor a mayor, muéstrala, inviértela y vuelve a mostrarla.

    Ejercicio 6. Usuarios separados por comas

    Pide nombres separados por comas, conviértelos en una lista con split() y muestra cada usuario en una línea.

    Ejercicio 7. Calcular la media

    Pide varias notas separadas por ;, conviértelas a números y calcula la media.

    Ejercicio 8. Conversión mediante comprensión

    Partiendo de:

    numeros = ["10", "20", "30", "40"]

    crea una lista de enteros mediante una comprensión de listas.
