    Ejercicios

    Ejercicio 1. Separador

    Crea una función:

    imprime_linea(caracter, longitud)

    que muestre una línea formada por el carácter indicado.

    Ejemplo:

    imprime_linea("#", 5)

    Salida:

    #####

    Ejercicio 2. Información de un servidor

    Crea una función:

    muestra_servidor(nombre, ip)

    que muestre ambos datos.

    Ejercicio 3. Parámetro opcional

    Modifica el ejercicio anterior para añadir:

    estado="activo"

    como valor por defecto.

    Ejercicio 4. Validar un puerto

    Crea:

    puerto_valido(puerto)

    que devuelva True si el puerto está entre 1 y 65535 y False en caso contrario.

    Ejercicio 5. Contar servicios

    Crea una función que reciba una lista de servicios y devuelva cuántos contiene.

    Ejemplo:

    servicios = ["ssh", "http", "https"]

    El resultado debe ser:

    3

    Ejercicio 6. Media de latencias

    Crea una función que reciba una lista de latencias y devuelva su media.

    Por ejemplo:

    latencias = [10, 20, 30]

    debe devolver:

    20.0
