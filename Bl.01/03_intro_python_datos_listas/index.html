    Listas

    Las listas permiten almacenar varios valores dentro de una misma variable.

    Por ejemplo:

    puertos = [22, 80, 443, 8080]

    Una lista puede contener números, cadenas u otros tipos de datos. En estos ejemplos veremos cómo crear listas, acceder a sus elementos, obtener su longitud, extraer partes mediante slicing, modificar elementos, comprobar si una lista está vacía, recorrer listas, buscar elementos, ordenarlas y convertir cadenas en listas.

    También aparecen dos contenidos algo más avanzados: las comprensiones de listas y el uso de try/except.

# Lista de enteros
puertos = [22, 80, 443, 8080]

# mostar la lista y su tipo
print(puertos)
print(type(puertos))

print(puertos[0])

print("Nº de elementos de la lista:", len(puertos))

# Ejemplos formas de recorrer lista
lista_IP = ["192.168.1.1", "10.10.10.10", "172.16.100.100", "195.172.1.1"]

# los elementos con for
for x in lista_IP:
    print("IP: ", x)

# los elementos y sus índices con for
for i in range(len(lista_IP)):
    print(f"IP[{i}]: {lista_IP[i]}")

# Avanzado: comprensión de listas: [expresión for elemento in iterable]
[print(" -", x) for x in lista_IP ]

    1.2. Crear una lista

    Una lista se escribe entre corchetes:

    puertos = [22, 80, 443, 8080]

    En este caso contiene cuatro números enteros. Podemos mostrarla completa con print(puertos) y comprobar su tipo con type(puertos).

    1.3. Acceder a elementos mediante su posición

    Los elementos se numeran empezando en 0:

    print(puertos[0])
print(puertos[1])

    Los índices comienzan en 0

    El primer elemento de una lista está en la posición 0, no en la 1.

    1.4. Obtener la longitud con len()

    len(puertos)

    devuelve el número de elementos de la lista.

    1.5. Obtener una parte de una lista

    Podemos utilizar slicing:

      frutas[1:4]

    La posición inicial se incluye y la final no. También podemos guardar el fragmento obtenido en una nueva lista:

    nueva_lista =   frutas[1:4]

    1.6. Acceder al último elemento

    Podemos calcular su posición:

      frutas[len(  frutas) - 1]

    pero normalmente es más sencillo utilizar un índice negativo:

      frutas[-1]

    Los índices negativos cuentan desde el final: -1 es el último elemento, -2 el penúltimo, etc.

    1.7. Modificar elementos

    Las listas son mutables, por lo que podemos modificar sus elementos directamente:

      frutas[0] = "watermelon"

    Listas y cadenas no se comportan igual

    Las cadenas son inmutables, pero las listas sí permiten modificar sus elementos.

    2. Comprobar si una lista está vacía

    Podemos hacerlo comprobando su longitud:

    if len(lista) != 0:
    print("La lista contiene elementos")
else:
    print("Lista vacía")

    Python permite una forma más sencilla:

    if lista:
    print("La lista contiene elementos")
else:
    print("Lista vacía")

    Una lista vacía ([]) se considera falsa en una condición; una lista con elementos se considera verdadera.

    3. Recorrer una lista

    Si solo necesitamos los valores:

    for x in lista_IP:
    print("IP: ", x)

    Si necesitamos también las posiciones:

    for i in range(len(lista_IP)):
    print(f"IP[{i}]: {lista_IP[i]}")

    3.1. Comprensión de listas

    El script incluye:

    [print(" -", x) for x in lista_IP]

    La sintaxis general de una comprensión es:

    [expresion for elemento in iterable]

    Contenido avanzado

    Aunque esta construcción funciona, las comprensiones de listas se utilizan sobre todo para crear nuevas listas, no para ejecutar acciones como print().

    Para mostrar elementos es más claro:

    for x in lista_IP:
    print(" -", x)

    # BSUCAR elemento en la lista 

# Con in => True/False

lista_IP = ["192.168.1.1", "10.10.10.10", "172.16.100.100", "195.172.1.1"]
print("lista_IP", lista_IP)

ip = input("IP a buscar: ")
if ip in lista_IP:
    print(f"Yes, {ip} is in {lista_IP}") 
else:
    print(f"No, {ip} is not in {lista_IP}") 

# Buscar con index si necesitamos la posición 
# Nota: index genera excepción si no está

print("lista_IP", lista_IP)
ip = input("IP a buscar: ")

# pos = lista_IP.index(ip)  # Genera excepción si no está en la lista

# Para corregir excepción si no se encuentra
# a) usar in o count antes de index 
if ip in lista_IP:
    pos = lista_IP.index(ip) 
    print(f"{ip} está en la posición {pos}") 
else:
    print(f"{ip} NO está en {lista_IP}") 

# b) se añade bloque try/except  para evitarlo
try:
    pos = lista_IP.index(ip) 
    print(f"{ip} está en la posición {pos}") 
except ValueError:
    print(f"{ip} NO está en {lista_IP}")

    4.2. Buscar con in

    La forma más sencilla de comprobar si un elemento existe es:

    if ip in lista_IP:

    in produce True si el elemento está en la lista y False si no está.

    4.3. Obtener la posición con index()

    lista_IP.index(ip)

    devuelve la posición del elemento.

    Si el elemento no existe, Python genera una excepción ValueError. Por eso en el ejemplo se comprueba primero con in.

    4.4. Alternativa con try/except

    try:
    pos = lista_IP.index(ip)
    print(f"{ip} está en la posición {pos}")
except ValueError:
    print(f"{ip} NO está en {lista_IP}")

    Contenido algo más avanzado

    try/except sirve para controlar excepciones durante la ejecución. Para una primera aproximación a listas, comprobar antes con in resulta más sencillo.

    5. Ordenar y modificar listas

    5.1. Código completo

    # ordenar listas: sort ,reverse
edades = [19, 17, 23, 56, 48, 100, 31]
print("edades:", edades)

edades.sort()
print("edades tras edades.sort():", edades)
edades.reverse()
print("edades tras edades.reverse():", edades)

# Modificar la lista: añadir al final
print("edades:", edades)
edades.append(20)
print("edades tras edades.append(20):", edades)

# Modificar la lista: añadir en cualquier posición: 
edades.insert(1, 44)
print("edades tras edades.insert(1,44):", edades)

# Borrar un elemento
eliminado = edades.pop() 
print("edades tras eliminado = edades.pop()", edades)
print("eliminado:", eliminado )

eliminado = edades.pop(0)
print("edades tras eliminado = edades.pop(0)", edades)
print("eliminado:", eliminado )

# Vaciar la lista
edades.clear()
print("edades tras clear", edades)

## CONVERTIR string en lista: split
users = "ana:luis:alfredo"
lista = users.split(":")
print("users:", users)
print("type(users)", type(users))
print("lista: ", lista)
print("type(lista)", type(lista))

# Ejemplo lectura notas con input y conversión a lista para calcular media
lectura = input("Notas separadas por el caracter ';': " )
print(lectura, type(lectura)) # es un string
notas = lectura.split(";") # es una lista
print(notas, type(notas))

suma = 0 # Almacena la suma de las notas
for x in notas:
    suma = suma + float(x)
media = suma/len(notas)
print("Suma: ", suma)
print(f"Media: {media:.2f}")

# Avanzado: conversión a números de una lista de string 
edades = ["14", "21", "17", "33", "45"]
print("type(edades[0]):", type(edades[0]))
# comprensión de listas
edades =  [int(x) for x in edades]
print("type(edades[0]):", type(edades[0]))

    5.2. Ordenar con sort()

    edades.sort()

    ordena la lista de menor a mayor y modifica la lista original.

    5.3. Invertir con reverse()

    edades.reverse()

    invierte el orden actual.

    Ordenar e invertir no es lo mismo

    reverse() no ordena: solo invierte el orden existente.

    5.4. Añadir con append()

    edades.append(20)

    añade un elemento al final.

    5.5. Insertar en una posición

    edades.insert(1, 44)

    inserta 44 en la posición 1.

    5.6. Eliminar con pop()

    eliminado = edades.pop()

    elimina el último elemento y lo devuelve. También podemos indicar una posición:

    eliminado = edades.pop(0)

    5.7. Vaciar una lista con clear()

    edades.clear()

    elimina todos sus elementos.

    6. Convertir una cadena en lista con split()

    Si tenemos:

    users = "ana:luis:alfredo"

    podemos dividir la cadena usando : como separador:

    lista = users.split(":")

    El resultado será:

    ["ana", "luis", "alfredo"]

    7. Leer varios valores y calcular una media

    Si el usuario introduce:

    5;7.5;8;6

    la instrucción:

    notas = lectura.split(";")

    produce una lista similar a:

    ["5", "7.5", "8", "6"]

    Siguen siendo cadenas

    split() crea una lista, pero sus elementos siguen siendo de tipo str.

    Por eso el programa convierte cada elemento al sumar:

    for x in notas:
    suma = suma + float(x)

    Finalmente calcula:

    media = suma / len(notas)

    8. Convertir todos los elementos de una lista

    Partimos de:

    edades = ["14", "21", "17", "33", "45"]

    Con una comprensión:

    edades = [int(x) for x in edades]

    se obtiene una nueva lista de enteros.

    Contenido avanzado

    Una forma equivalente con un for tradicional sería:

    nueva_lista = []

for x in edades:
    nueva_lista.append(int(x))

edades = nueva_lista
