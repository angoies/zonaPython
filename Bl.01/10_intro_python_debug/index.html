    Depuración de scripts Python en Linux con VS Code

    1. Objetivos de aprendizaje

    Al finalizar este tema debería ser capaz de:

    • distinguir entre errores de sintaxis, errores en tiempo de ejecución y errores lógicos;
    • seguir de forma razonada el flujo de ejecución de un programa;
    • utilizar print() como técnica básica de diagnóstico;
    • utilizar breakpoint() y pdb;
    • depurar scripts con Visual Studio Code;
    • inspeccionar variables, expresiones y la pila de llamadas;
    • utilizar puntos de ruptura normales y condicionales;
    • registrar información de diagnóstico con logging;
    • aplicar una metodología sistemática para localizar errores lógicos.

    2. Introducción

    La depuración o debugging es el proceso mediante el cual se analiza la ejecución de un programa para localizar y corregir errores. No todos los errores se presentan de la misma forma.

    2.1. Errores de sintaxis

    Se producen cuando el código no cumple las reglas del lenguaje.

    edad = 20

if edad >= 18
    print("Mayor de edad")

    Python no puede ejecutar el programa porque falta : al final de la condición.

    SyntaxError: expected ':'

    Idea clave

    Los errores de sintaxis suelen ser sencillos de localizar porque Python indica el punto en el que detecta el problema.

    2.2. Errores en tiempo de ejecución

    El programa comienza a ejecutarse, pero se produce una excepción.

    numero = 10
divisor = 0

resultado = numero / divisor

    Python mostrará un mensaje parecido a:

    ZeroDivisionError: division by zero

    La información mostrada forma parte del traceback, que indica por qué ha fallado el programa y en qué línea se produjo el error.

    2.3. Errores lógicos

    Son los errores en los que centrarse especialmente. El programa se ejecuta sin excepciones, pero produce un resultado incorrecto.

    precios = [10, 20, 30]

total = 0

for precio in precios:
    total = precio

print(total)

    El programa muestra:

    30

    pero el resultado correcto debería ser:

    60

    El problema está en:

    total = precio

    En cada iteración se sustituye (y no actualiza) el valor anterior. La operación correcta sería:

    total += precio

    Importante

    En un error lógico Python no tiene por qué mostrar ningún mensaje. El programa puede terminar aparentemente bien aunque el resultado sea incorrecto.

    3. Una metodología para localizar errores

    Depurar no consiste en modificar líneas al azar hasta que el programa funcione. Es preferible seguir un proceso.

    1. Reproducir el fallo
        ↓
2. Determinar el resultado esperado
        ↓
3. Reducir los datos de entrada
        ↓
4. Localizar la zona sospechosa
        ↓
5. Observar variables
        ↓
6. Añadir print() o logging
        ↓
7. Colocar un breakpoint
        ↓
8. Avanzar paso a paso
        ↓
9. Identificar la causa
        ↓
10. Corregir y volver a probar

    3.1. Determinar el resultado esperado

    Si tiene:

    notas = [7, 8, 5, 9]

    la media esperada es 7.25: antes de depurar debe saber qué resultado debería obtenerse.

    3.2. Reproducir el fallo

    Es importante disponer de datos que hagan aparecer el error siempre. Los datos pequeños y fáciles de comprobar manualmente son ideales.

    3.3. Reducir el problema

    Si un script procesa miles de registros, puede probar temporalmente con unos pocos para hacer la depuración "manejable".

    usuarios = [
    {"nombre": "ana", "activo": True},
    {"nombre": "juan", "activo": False},
]

    3.4. Formular hipótesis

    Por ejemplo:

    Creo que el contador se reinicia en cada iteración.

    La depuración consistirá en comprobar si esa hipótesis es cierta.

    Depurar es comprobar

    Una buena depuración intenta responder preguntas como:

    • ¿Qué valor tiene esta variable?
    • ¿Qué rama del if se está ejecutando?
    • ¿Cuántas veces entra en este bucle?
    • ¿Dónde cambia por primera vez el valor esperado?

    4. Primera técnica: depuración con print()

    La técnica más sencilla consiste en añadir mensajes temporales al programa.

    numeros = [10, 20, 30]

total = 0

for numero in numeros:
    total = numero
    print("numero:", numero)
    print("total:", total)

print("Resultado:", total)

    Salida:

    numero: 10
total: 10
numero: 20
total: 20
numero: 30
total: 30

    Puede comprobar que total no acumula los valores.

    4.1. Mensajes claros

    Es mejor:

    print("total =", total)

    que:

    print(total)

    También puede utilizar f-strings:

    print(f"numero={numero}, total={total}")

    4.2. Inspeccionar tipos

    Algunos errores se deben a tipos inesperados.

    edad = input("Edad: ")

print(edad)
print(type(edad))

    Resultado:

    20
<class 'str'>

    Aunque el usuario escriba un número, input() devuelve una cadena.

    4.3. Limitaciones de print()

    print() es útil, pero tiene limitaciones:

    • obliga a modificar el código;
    • puede generar demasiada salida;
    • es fácil olvidar eliminar mensajes tras la depuración;
    • no permite detener el programa;
    • no permite avanzar instrucción a instrucción;
    • resulta incómodo en programas grandes.

    5. breakpoint() y pdb

    Python incorpora:

    breakpoint()

    Cuando la ejecución alcanza esa línea, el programa se detiene y abre el depurador interactivo pdb.

    numeros = [10, 20, 30]

total = 0

for numero in numeros:
    breakpoint()
    total += numero

print(total)

    Podemos ejecutar el programa desde Linux:

    python3 programa.py

    Cuando se alcance el punto de interrupción aparecerá:

    (Pdb)

    5.1. Comandos básicos de pdb

    Comando Función
    p expresion Mostrar una variable o expresión
    n Ejecutar la siguiente línea
    s Entrar en una función
    c Continuar hasta el siguiente breakpoint
    l Mostrar código alrededor de la línea actual
    q Salir del depurador

    5.2. Ejemplo

    def calcular_descuento(precio, porcentaje):
    descuento = precio * porcentaje / 100
    precio_final = precio - descuento
    return precio_final


precio = 100
porcentaje = 20

breakpoint()

resultado = calcular_descuento(precio, porcentaje)

print(resultado)

    Podemos consultar:

    (Pdb) p precio
100

    o:

    (Pdb) p porcentaje
20

    Diferencia entre n y s

    n ejecuta una llamada a función sin entrar en ella.

    s entra en la función para depurarla línea a línea.

    6. Preparar Visual Studio Code

    Para depurar Python con VS Code necesitamos la extensión oficial de Python.

    6.1. Seleccionar el intérprete

    Abre la paleta de comandos:

    Ctrl + Shift + P

    Busca:

    Python: Select Interpreter

    En Linux puede aparecer, por ejemplo:

    /usr/bin/python3

    o un entorno virtual:

    proyecto/.venv/bin/python

    Comprueba el intérprete

    Si VS Code usa un intérprete distinto al utilizado en la terminal, pueden aparecer errores con módulos o dependencias que aparentemente están instalados.

    7. Puntos de ruptura en VS Code

    Supongamos este programa:

    def calcular_media(lista):
    suma = 0

    for x in lista:
        suma = x

    return suma / len(lista)


precios = [7, 8, 5, 9]

media = calcular_media(precios)

print("Media:", media)

    Para colocar un breakpoint, haz clic a la izquierda del número de línea.

    Aparecerá un punto rojo.

    Un buen lugar sería:

    suma = 0

    7.1. Iniciar la depuración

    Abre:

    Run and Debug

    o usa:

    Ctrl + Shift + D

    Después inicia el programa con:

    F5

    8. Controles principales del depurador

    === "Continue"

    Continúa la ejecución hasta el siguiente breakpoint.

```text
F5
```

    === "Step Over"

    Ejecuta la línea actual y pasa a la siguiente sin entrar en funciones.

```text
F10
```

    === "Step Into"

    Entra dentro de una función llamada en la línea actual.

```text
F11
```

    === "Step Out"

    Continúa hasta salir de la función actual.

```text
Shift + F11
```

    Qué control usar

    Si sospechas que una función contiene el error, utiliza Step Into.
    Si ya confías en esa función, utiliza Step Over.

    9. Inspección de variables

    Cuando el programa se detiene, VS Code muestra el panel Variables.

    En el ejemplo anterior podemos observar:

    x = 8
suma = 8
lista = [7, 8, 5, 9]

    En la siguiente vuelta:

    x = 5
suma = 5

    El comportamiento revela el problema:

    suma = x

    debería ser:

    suma += x

    10. Watch

    El panel Watch permite observar expresiones durante la ejecución.

    Podemos añadir:

    suma

    o:

    suma / len(lista)

    También condiciones:

    suma > 20

    Cuándo usar Watch

    Watch es especialmente útil para seguir contadores, acumuladores, índices y condiciones booleanas a lo largo de varias iteraciones.

    11. Call Stack

    El panel Call Stack muestra la cadena de funciones que ha llevado hasta el punto actual.

    def aplicar_iva(precio):
    return precio * 1.21


def calcular_total(precios):
    total = 0

    for precio in precios:
        total += aplicar_iva(precio)

    return total


def generar_factura():
    precios = [10, 20, 30]
    return calcular_total(precios)


resultado = generar_factura()

print(resultado)

    Durante la ejecución podemos encontrar:

    aplicar_iva()
calcular_total()
generar_factura()
main

    Es decir:

    main
 ↓
generar_factura()
 ↓
calcular_total()
 ↓
aplicar_iva()

    12. Debug Console

    La Debug Console permite evaluar expresiones mientras el programa está detenido.

    Por ejemplo:

    precio

    precio * 1.21

    len(precios)

    Esto permite comprobar hipótesis sin modificar el script.

    13. Breakpoints condicionales

    Un bucle puede ejecutarse cientos de veces.

    Podemos crear un punto de ruptura que solo se active cuando se cumpla una condición.

    Ejemplo:

    for numero in numeros:
    procesar(numero)

    Condición del breakpoint:

    numero == 50

    o:

    numero < 0

    Caso de uso

    Si un error solo aparece al procesar el usuario con identificador 153, no tiene sentido detenerse en los 152 usuarios anteriores.

    14. Errores lógicos frecuentes

    14.1. Acumuladores mal actualizados

    Incorrecto:

    total = 0

for precio in precios:
    total = precio

    Correcto:

    total = 0

for precio in precios:
    total += precio

    14.2. Reiniciar variables dentro del bucle

    Incorrecto:

    contador = 0

for numero in numeros:
    contador = 0

    if numero % 2 == 0:
        contador += 1

    14.3. Sustituir una lista en lugar de añadir

    Incorrecto:

    resultado = []

for numero in numeros:
    if numero > 20:
        resultado = [numero]

    Correcto:

    resultado.append(numero)

    14.4. Errores en valores límite

    if edad > 18:

    Si una persona de 18 años debe cumplir la condición, debería ser:

    if edad >= 18:

    Para comprobar límites es útil probar:

    17
18
19

    Idea final

    Depurar consiste en encontrar el primer punto en el que el comportamiento real del programa deja de coincidir con el comportamiento esperado.
