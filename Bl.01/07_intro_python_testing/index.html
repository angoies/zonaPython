    Introducción a Python - Testing

    Introducción al testing

    Módulo pytest

    Pytest es un framework de pruebas en Python que permite escribir y ejecutar tests unitarios de forma sencilla y sin código repetitivo.

    Instalación pytest

    Creamos un entorno virtual para instalar pytest dentro.

    clases@ssd:~/testing$ python3 -m venv venv
clases@ssd:~/testing$ source venv/bin/activate
(venv) clases@ssd:~/testing$

    Instalar y verificar

    (venv) clases@ssd:~/testing$ pip install pytest
Collecting pytest
  Downloading pytest-9.1.1-py3-none-any.whl.metadata (7.6 kB)
....
Successfully installed iniconfig-2.3.0 packaging-26.3 pluggy-1.6.0 pygments-2.21.0 pytest-9.1.1
(venv) clases@ssd:~/testing$  pytest --version

(venv) clases@ssd:~/testing$

    Fichero de test

    El fichero con las pruebas o test debe cumplir:

    • Nombres de archivo: debe comenzar con el prefijo test_(por ejemplo test_operaciones.py).
    • Funciones de prueba: se definen dentro del archivo usando también el prefijo test_.
    • Comprobaciones: se utiliza la palabra clave nativa assert para comprobar que el resultado obtenido al llamar a la función que se prueba coincide con el esperado.

    En el siguiente ejemplo queremoc comprobar la función comprueba_clave incluida en el fichero seguridad.py:

    # File: seguridad.py
def comprueba_clave(login, password):
  valida = True
  claves_prohibidas = {
        "123456789012",
        "password12345",
        "administrador2026"
  }

  if len(password) <10:
    valida = False
  elif password in claves_prohibidas:
    valida = False
  elif login in password:
    valida = False

  return valida

    Y el fichero con las pruebas en una primera versión:

    # File: test_seguridad.py

import pytest
# El nombre del fichero seguridad.py es el nombre del módulo
#   se importa la función a probar
from seguridad import comprueba_clave 


def test_clave_valida():
    """Clave de más de 10 caracteres válida"""
    assert comprueba_clave("usuario123", "ClaveMuySegura2026!") is True

def test_clave_corta_menos_de_10_caracteres():
    """Clave con menos de 10 caracteres."""
    assert comprueba_clave("usuario", "12345679") is False

    Ejecución

    Escriba pytest en su terminal para descubrir y ejecutar automáticamente las pruebas. Puede añadir la opción -v para ver más detalles.

    (venv) clases@ssd:~/testing$  pytest test_seguridad.py

    Ejercicio

    1. Ampliar los casos de prueba en el fichero de test para verificar que se cumplen todos los requisitos: no estar en la lista de claves prohibidas y que el login no sea parte de la clave
    2. Añadir una prueba con logín administrador2026 y clave "Administrador2026". Esta clave debería ser inválida y en cambio pasa las pruebas. Pase al siguinte apartado.
    3. Modificar la función comprueba_clave para que no sea case-sensitive. Añadir casos de prueba.
