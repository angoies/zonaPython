    Introducción a Python - Excepciones

    1. Introducción

    Cuando un programa encuentra un problema durante su ejecución, Python puede generar una excepción. Ya vimos un ejemplo al utilizar os.mkdir() para crear directorios. Por ejemplo:

    import os

os.mkdir("/root/nueva_carpeta")

    Si el usuario que ejecuta el programa no tiene permisos para crear el directorio, Python interrumpe la ejecución y genera una excepción. Una posible salida sería:

    Traceback (most recent call last):
  File "13_excepciones.py", line 25, in <module>
    os.mkdir("/root/nueva_carpeta")
PermissionError: [Errno 13] Permission denied: '/root/nueva_carpeta'

    En este caso, la excepción es:

    PermissionError

    2. ¿Qué es una excepción?

    Una excepción representa una situación anómala que ocurre mientras el programa se está ejecutando. Algunos ejemplos habituales son:

    • intentar convertir a número un texto que no contiene un número;
    • dividir entre cero;
    • acceder a una posición que no existe en una lista;
    • buscar una clave inexistente en un diccionario;
    • abrir un fichero que no existe;
    • crear un directorio sin permisos suficientes.

    Si no tratamos la excepción, el programa normalmente se detiene y Python muestra un traceback.

    Excepción no significa necesariamente error de programación

    Una excepción también puede representar situaciones perfectamente posibles durante la ejecución.

    Por ejemplo, que un usuario escriba un dato incorrecto o que un fichero no exista.

    3. Excepciones con os.mkdir()

    La función os.mkdir(ruta) no devuelve un código de error cuando algo falla. Si el directorio se crea correctamente, la función termina y devuelve:

    None

    Si se produce un problema, genera una excepción. Algunas excepciones habituales son:

    • FileExistsError: Se produce si el directorio ya existe.
    • PermissionError: Se produce si no tenemos permisos suficientes.
    • FileNotFoundError: Puede aparecer si algún directorio intermedio no existe.

    4. La estructura try ... except

    Para evitar que el programa se detenga automáticamente podemos capturar la excepción.La estructura básica es:

    try:
    # código que puede generar una excepción
except TipoDeExcepcion:
    # qué hacer si ocurre

    Por ejemplo:

    import os

try:
    os.mkdir("/root/nueva_carpeta")
except PermissionError:
    print("No tiene permisos para crear el directorio")

    5. Tratar varias excepciones

    Podemos utilizar varios bloques except.

    import os

ruta = input("Directorio a crear: ")

try:
    os.mkdir(ruta)

except FileExistsError:
    print("El directorio ya existe")

except PermissionError:
    print("No tiene permisos para crear el directorio")

except FileNotFoundError:
    print("Algún directorio intermedio no existe")

    Cada except trata un tipo de excepción diferente.

    6. Obtener información sobre la excepción

    Podemos guardar el objeto de la excepción en una variable. Vea un ejemplo:

    try:
    os.mkdir("/root/nueva_carpeta")

except PermissionError as e:
    print("Error de permisos")
    print("Detalle:", e)

    La variable e contiene información generada por Python sobre la excepción.

    7. Captura genérica con Exception

    También podemos capturar la excepción sin especificar el tipo usando Exception. Sería similar a un "caso por defecto";

    try:
    os.mkdir(ruta)

except FileExistsError:
    print("El directorio ya existe")

except PermissionError:
    print("No tiene permisos")

except Exception as e:
    print("Se ha producido otro error:", e)

    Las excepciones específicas deben ir primero

    Los casos específicos deben aparecer antes que Exception, dejando el caso genérico al final.

    Usar sólo una excepción genérica puede ocultar información útil. Es preferible capturar excepciones concretas cuando sabemos cuáles pueden ocurrir y utilizar Exception solo como último caso cuando tenga sentido.

    8. Ejemplos excepciones

    8.1. input() y ValueError

    try:
    edad = int(input("Edad: "))
    print("Edad:", edad)

except ValueError:
    print("Debe introducir un número entero")

    Si el usuario escribe un texto que no se puede convertir con int(), se produce ValueError.

    8.2. división por cero

    try:
    a = int(input("Dividendo: "))
    b = int(input("Divisor: "))

    resultado = a / b
    print("Resultado:", resultado)

except ValueError:
    print("Debe introducir números enteros")

except ZeroDivisionError:
    print("No se puede dividir entre cero")

    Aquí pueden ocurrir dos problemas distintos:

    • el usuario introduce algo que no es un entero;
    • el divisor es 0.

    9. Anexo I: else y finally

    9.1. else

    Se puede añadir un bloque else a try qeu se ejecuta solo si no se produce ninguna excepción.

    try:
    numero = int(input("Número: "))

except ValueError:
    print("Valor incorrecto")

else:
    print("Número correcto:", numero)

    9.2. finally

    El bloque finally se ejecuta siempre, tanto si se produce una excepción como si no.

    try:
    numero = int(input("Número: "))
    print("Número:", numero)

except ValueError:
    print("Valor incorrecto")

finally:
    print("Fin del intento")

    finally es útil para tareas de limpieza que deben ejecutarse siempre.

    9.3. Estructura completa

    try:
    ...
except TipoError:
    ...
else:
    ...
finally:
    ...

    El significado es:

    • try: código que puede generar una excepción;
    • except: qué hacer si ocurre;
    • else: qué hacer si todo ha ido bien;
    • finally: qué hacer siempre.

    No es necesario utilizar todos los bloques.

    10. Ejemplo completo con directorios

    import os

ruta = input("Directorio a crear: ")

try:
    os.mkdir(ruta)

except FileExistsError:
    print("El directorio ya existe")

except PermissionError:
    print("No tiene permisos para crear el directorio")

except FileNotFoundError:
    print("Algún directorio intermedio no existe")

except Exception as e:
    print("Se ha producido un error no previsto:")
    print(e)

else:
    print("Directorio creado correctamente")

finally:
    print("Fin del intento de creación")

    11. Anexo II: Excepciones habituales en Python

    Excepción Ejemplo
    ValueError int("hola")
    ZeroDivisionError 10 / 0
    IndexError acceder fuera de una lista
    KeyError usar una clave inexistente
    FileNotFoundError abrir un fichero inexistente
    FileExistsError crear un directorio que ya existe
    PermissionError acceder sin permisos

    11.1. IndexError con listas

    puertos = [22, 80, 443]

try:
    posicion = int(input("Posición: "))
    print(puertos[posicion])

except ValueError:
    print("Debe introducir un número")

except IndexError:
    print("La posición no existe")

    11.2. KeyError con diccionarios

    servidor = {
    "nombre": "web01",
    "ip": "192.168.1.20"
}

try:
    print(servidor["puerto"])

except KeyError:
    print("La clave no existe")

    Para una consulta sencilla también podemos utilizar:

    servidor.get("puerto")

    o comprobar previamente:

    if "puerto" in servidor:

    No todo debe resolverse con try

    A veces existe una forma más sencilla de evitar el problema.

    12. Anexo III: Recomendaciones

    12.1. Evitar bloques try demasiado grandes

    Es preferible limitar el try al código que realmente puede generar la excepción que queremos controlar.

    Por ejemplo:

    try:
    edad = int(input("Edad: "))
except ValueError:
    print("Edad incorrecta")

    resulta más claro que incluir muchas operaciones no relacionadas dentro del mismo try.

    12.2. Evitar except: sin indicar excepción

    Python permite:

    except:
    print("Error")

    pero normalmente conviene evitar esta forma. Es preferible:

    except ValueError:

    o si necesitamos un caso genérico:

    except Exception as e:
