    Introducción a Python: uso módulos y funciones

    En administración de sistemas, las funciones son bloques de código reutilizables diseñados para automatizar tareas repetitivas. Las funciones pueden ser propias o que ya vengan en módulos de la biblioteca estándar o de terceros

    Por ejemplo, el módulo os de la biblioteca estándar de Python permite interactuar directamente con el sistema operativo (archivos, directorios, procesos y rutas) de forma independiente del SO.

    1. Usando un módulo

    Para invocar (ejecutar) una función que pertenece a un módulo en Python, se sigue esta sintaxis:

    1. Importar el módulo: Declarar la dependencia al inicio del script (import modulo).
    2. Notación de punto y paréntesis: Conectar el nombre del módulo con la función (modulo.funcion()).
    3. Argumentos entre paréntesis(): Puede no tener argumentos, o que sean obligatorios u opcionales, puede necesitar uno o varios, etc.

    2. Función SIN parámetros

    Una función sin parámetros no requiere datos de entrada para realizar su trabajo; obtiene la información directamente del entorno de ejecución. Es el caso de os.getcwd():

    • Propósito: Devuelve la ruta absoluta del directorio de trabajo actual (Get Current Working Directory).
    • Equivalente CLI: Comando pwd en Linux/macOS o cd en Windows CMD.
    import os

# Se invoca dejando los paréntesis vacíos
directorio_actual = os.getcwd()

print(f"El script se está ejecutando desde: {directorio_actual}")

    3. Función CON parámetro obligatorio

    Una función con parámetros requiere que le pases uno o más datos (argumentos) dentro de los paréntesis para poder operar. Es el caso de os.mkdir(path):

    • Propósito: Crea un nuevo directorio en el sistema de archivos en la ruta indicada.
    • Equivalente CLI: Comando mkdir <nombre_directorio>.
    import os

# Definimos el argumento: el nombre de la carpeta que queremos crear
carpeta_backup = "/var/backups/diarios"

# Invocación pasando el parámetro (obligatorio)
os.mkdir(carpeta_backup)

print(f"Directorio creado correctamente en: {carpeta_backup}")

    Nota para administradores: Si la carpeta ya existe o no se tienen permisos de escritura en la ruta destino, Python interrumpirá el script con una excepción. A diferencia de los scripts de Bash o las llamadas en C (donde las funciones devuelven un código de salida como 0 o 1), os.mkdir() gestiona los resultados mediante el flujo de excepciones:

    • Si la carpeta se crea correctamente: La función finaliza en silencio devolviendo None.
    • Si ocurre un error: No devuelve un código de error, sino que interrumpe la ejecución lanzando una excepción:
      • FileExistsError: La carpeta ya existe en esa ruta.
      • PermissionError: El usuario que ejecuta el script no tiene permisos de escritura.
      • FileNotFoundError: La ruta intermedia especificada no existe (por ejemplo, intentar crear a/b/c cuando a o b no existen).

    4. Función CON parámetro opcional

    El método os.listdir(path) retorna:

    • con parametro path el contenido del directorio indicado en path
    • sin parámetro path el contenido del directorio actual
    # Método con argumento opcional
files_dir_actual = os.listdir()
files_dir_backup = os.listdir(carpeta_backup)
print(files_dir_actual)
print(files_dir_backup)

    5. Función con más de un parámetro

    Un ejemplo con dos parámetros (obligatorios) es la función os.rename(src, dst) que sirve para renombrar o mover un archivo o directorio de una ubicación a otra. Es equivalente al comando mv en Linux:

    1. Primer parámetro (src / source): La ruta del archivo o carpeta original que ya existe.
    2. Segundo parámetro (dst / destination): La ruta o nombre final del archivo o carpeta.
    import os

# 1. Definimos los datos que necesita la función
log_actual = "/var/log/servidor.log"
log_rotado = "/var/log/servidor.log.old"

# 2. Invocamos la función pasando ambos parámetros separados por una coma
#    El orden es importante
os.rename(log_actual, log_rotado)

print("El archivo se ha renombrado correctamente.")

    Al igual que os.mkdir(), devuelve None y gestiona los fallos mediante excepciones (FileNotFoundError, PermissionError, etc.).

    6. Argumentos: Posicionales vs con nombre

    En Python cuando una función recibe varios parámetros se pueden pasar de dos formas. Usemos como ejemplo os.rename(src, dst):

    1. Por posición (lo más habitual):El orden de los argumentos dentro del paréntesis determina a qué parámetro corresponde cada uno (el primer valor va a src y el segundo a dst).

      os.rename("/tmp/archivo.txt", "/tmp/archivo_nuevo.txt")

    2. Por nombre de parámetro (keyword arguments): Puede especificar explícitamente el nombre del parámetro. En este caso, el orden en el que los escriba no importa.

      os.rename(dst="/tmp/archivo_nuevo.txt", src="/tmp/archivo.txt")
