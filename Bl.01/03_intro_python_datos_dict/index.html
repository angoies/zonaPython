    Introducción a Python: Diccionarios

    Los diccionarios son estructuras de datos que permiten almacenar información utilizando pares de clave y valor.

    Por ejemplo:

    coche = {
    "marca": "Seat",
    "modelo": "Ateca",
    "color": "blanco",
    "kilometros": 125000
}

    En este diccionario:

    • "marca" es una clave y "Seat" es su valor;
    • "modelo" es una clave y "Ateca" es su valor;
    • "color" es una clave y "blanco" es su valor;
    • "kilometros" es una clave y 125000 es su valor.

    Los diccionarios resultan especialmente útiles cuando queremos agrupar varios datos relacionados y acceder a ellos mediante un nombre significativo.

    # Dictionaries are used to store data values in key:value pairs.
# A dictionary is a collection which is ordered*, changeable and do not allow duplicates.

coche = {
    "marca": "Seat",
    "modelo": "Ateca",
    "color": "blanco",
    "kilometros": 125000
}

# muestra el diccionario completo
print("coche:", coche)

# Mostar el valor de una clave: 2 posibilidades
# a) muestra un elemento con notación []
print('coche["color"]:', coche["color"])
print('coche["kilometros"]:', coche["kilometros"])
# b) muestra un elemento con método get
print('coche.get("modelo"):', coche.get("modelo"))


# Recorrer los valores del diccionario y sus claves
print("Bucle for que recorre diccionario")
for clave in coche:
    print(" *", clave, "=>", coche[clave])

# Otra forma de recorrer: items()
# `items()` permite obtener directamente la clave y el valor 
#  en cada iteración. Rn muchos casos resulta más cómodo y legible.
print("Bucle for que recorre diccionario con .items()")
for clave, valor in coche.items():
    print(" - ", clave, "=>", valor)

# Modificar dicccionario: dos posibilidades
# a) con notación []
coche["color"] = "gris"
# b) con métoddo update
coche.update({"kilometros": 99999}) 
print("coche tras modificaciones:", coche)

# Añadir nueva clave a un diccionario
coche["taller"] = "Alterio reparaciones"
print("coche tras añadir clave:", coche)

# uso de values() y keys() 
valores = coche.values()
print("valores:", valores)
claves = coche.keys()
print("keys:", claves)

# las variables asignadas con values y keys()
#  se actualizan tras cambios en el diccionario
print('Se añade precio: coche["precio"] = 17000')
coche["precio"] = 17000
print("valores:", valores)
print("keys:", claves)

    2. Crear un diccionario

    Un diccionario se escribe utilizando llaves:

    coche = {
    "marca": "Seat",
    "modelo": "Ateca",
    "color": "blanco",
    "kilometros": 125000
}

    Cada elemento tiene la forma:

    clave: valor

    Por ejemplo:

    "marca": "Seat"

    La clave es:

    marca

    y el valor asociado es:

    Seat

    Claves y valores

    En una lista accedemos a los elementos normalmente mediante su posición:

    lista[0]

    En un diccionario utilizamos una clave:

    coche["marca"]

    Esto hace que el código pueda resultar más descriptivo.

    3. Mostrar el diccionario completo

    Podemos mostrar todo el diccionario utilizando print():

    print("coche:", coche)

    Obtendremos un resultado similar a:

    coche: {'marca': 'Seat', 'modelo': 'Ateca', 'color': 'blanco', 'kilometros': 125000}

    4. Acceder a un valor mediante su clave

    Podemos utilizar corchetes:

    coche["color"]

    Por ejemplo:

    print(coche["color"])

    mostrará:

    blanco

    También podemos consultar:

    coche["kilometros"]

    y obtendremos:

    125000

    La clave nos permite indicar directamente qué dato queremos consultar.

    5. Acceder con get()

    Otra posibilidad es utilizar el método:

    get()

    Por ejemplo:

    coche.get("modelo")

    devuelve:

    Ateca

    Por tanto:

    print(coche.get("modelo"))

    es otra forma de consultar un valor.

    5.1. Diferencia entre [] y get()

    Mientras la clave exista, estas dos expresiones devuelven el mismo resultado:

    coche["modelo"]

    coche.get("modelo")

    La diferencia aparece cuando la clave no existe.

    Si intentamos:

    coche["precio"]

    antes de haber creado esa clave, Python genera:

    KeyError

    Sin embargo:

    coche.get("precio")

    devuelve por defecto:

    None

    sin detener el programa.

    get() permite indicar un valor por defecto

    Podemos escribir:

    coche.get("precio", 0)

    Si "precio" no existe, obtendremos 0.

    6. Recorrer un diccionario con for

    El ejemplo utiliza:

    for x in coche:
    print(" *", x, "=>", coche[x])

    Cuando recorremos directamente un diccionario:

    for x in coche:

    la variable x va tomando las claves del diccionario.

    Por ejemplo:

    marca
modelo
color
kilometros

    Podemos utilizar la clave para consultar su valor:

    coche[x]

    De esta forma podemos mostrar ambos:

    marca => Seat
modelo => Ateca
color => blanco
kilometros => 125000

    7. Modificar un valor

    Los diccionarios son mutables, por lo que podemos cambiar sus valores.

    Por ejemplo:

    coche["color"] = "gris"

    La clave "color" ya existe, por lo que su valor pasa de:

    blanco

    a:

    gris

    8. Modificar mediante update()

    También podemos utilizar:

    coche.update({"kilometros": 99999})

    El método update() recibe otro diccionario con los datos que queremos actualizar.

    Después de ejecutar esa instrucción, el valor asociado a "kilometros" será:

    99999

    Para modificar un único elemento, tanto:

    coche["kilometros"] = 99999

    como:

    coche.update({"kilometros": 99999})

    son posibles.

    9. Añadir una nueva clave

    La misma sintaxis que utilizamos para modificar puede servir para crear un elemento nuevo:

    coche["taller"] = "Alterio reparaciones"

    Como la clave "taller" no existía, Python la añade al diccionario.

    Ahora tendremos también:

    taller => Alterio reparaciones

    Modificar o añadir

    Esta instrucción:

    diccionario[clave] = valor

    hace dos cosas posibles:

    • si la clave ya existe, modifica su valor;
    • si no existe, crea una nueva entrada.

    10. Obtener los valores con values()

    El método:

    coche.values()

    permite obtener una vista de todos los valores del diccionario.

    En el ejemplo:

    valores = coche.values()
print("valores:", valores)

    aparecerán los valores correspondientes a elementos como:

    Seat
Ateca
gris
99999
Alterio reparaciones

    11. Obtener las claves con keys()

    El método:

    coche.keys()

    permite obtener las claves.

    Por ejemplo:

    keys = coche.keys()
print("keys:", keys)

    incluirá claves como:

    marca
modelo
color
kilometros
taller

    12. Las vistas keys() y values() se actualizan

    El ejemplo guarda:

    valores = coche.values()
keys = coche.keys()

    Después añade:

    coche["precio"] = 17000

    Y vuelve a mostrar:

    print("valores:", valores)
print("keys:", keys)

    La nueva clave y el nuevo valor también aparecen.

    Esto sucede porque keys() y values() devuelven vistas del diccionario, no copias independientes.

    Una vista refleja los cambios

    Si el diccionario cambia, las vistas obtenidas con:

    keys()
values()

    reflejan esos cambios.

    13. Otra forma habitual de recorrer un diccionario

    Además de:

    for clave in coche:
    print(clave, coche[clave])

    existe el método items():

    for clave, valor in coche.items():
    print(clave, "=>", valor)

    items() permite obtener directamente la clave y el valor en cada iteración. Para muchos casos resulta especialmente cómodo y legible.
