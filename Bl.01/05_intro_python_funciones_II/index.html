    Introducción a Python

    Funciones II

    Las funciones son bloques de código reutilizables diseñados para automatizar tareas repetitivas.

    • Para definir una función en Python, se utiliza la palabra reservada def, seguida del nombre de la función, paréntesis () y dos puntos :. Todo el código que pertenezca a la función debe estar indentado (desplazado a la derecha).
    • Para ejecutar una función hay que invocarla por su nombre con los paréntesis ().

    Funciones SIN parámetros

    Una función sin parámetros no requiere datos de entrada para realizar su trabajo.

    # Función sin parámetros (siempre hace lo mismo)
def imprime_separador_simple():
    print("-"*25)

# Invocación ejecuta la función
imprime_separador_simple()
imprime_separador_simple()

    Funciones CON un parámetro

    Una función con parámetro requiere que le pase un parámetro o argumento dentro de los paréntesis para poder operar de forma dinámica.

    # Función con un parámetro
def imprime_separador(longitud):
    print("-"*longitud)

# Invocaciones con diferentes expresiones
imprime_separador(5)
imprime_separador(10)
tam = 15
imprime_separador(tam)
imprime_separador(tam*2)

    Funciones CON múltiples parámetros

    Puedes definir tantos parámetros como necesites, separándolos por comas. Cuando una función recibe varios parámetros, los datos se pueden enviar en la invocación de dos formas distintas:

    # Función con dos parámetros
def imprime_linea(letra, longitud):
    print(letra*longitud)

# Invocaciones posicionales con diferentes valores
imprime_linea("*", 5)
imprime_linea("#", tam)

# Invocación con nombres, puede cambiar el orden
imprime_linea(longitud=10, letra="&")

    Función que usa otra funcion

    # Utiliza en la definición otra función
def imprime_cabecera(titulo):
    imprime_linea("+",10)
    print(titulo)
    imprime_linea("-",10)

imprime_cabecera("Latencias")

    Funciones que retornan un resultado (return)

    En Python las funciones por defecto no devuelven ningún valor explícito, retornando None. Sin embargo, si necesita que la función devuelva un cálculo final al script principal se utiliza la palabra clave return.

    # función que DEVUELVE COMO RESULTADO la suma de valores de una lista
def sumaLista(lista):
    suma = 0
    for x in lista:
        suma += x   # suma = suma + x
    return suma

ventas = [1,2,3,4,5]
print("suma: ", sumaLista(ventas))

ventasTotales = sumaLista(ventas)
print("ventas:", ventas)
print("ventasTotales:", ventasTotales)

    # función que DEVUELVE COMO RESULTADO la media USANDO LA FUNCIÓN sumaLista 
def media(lista):
    media = sumaLista(lista)/len(lista)
    return media

edades = [23, 46, 56, 72, 12, 34]
print("edades:", edades)
print("sumaLista(edades):", sumaLista(edades))
print("media(edades):", media(edades))
