    Estructuras de datos combinadas: listas y diccionarios

    Hasta ahora ha trabajado con listas y diccionarios por separado. Sin embargo, en programas reales es muy habitual combinar ambas estructuras.

    En este tema se presentan dos casos frecuentes:

    1. un diccionario que contiene una lista;
    2. una lista cuyos elementos son diccionarios.

    1. Diccionario con una lista como valor

    Un diccionario puede almacenar distintos tipos de valores. entre ellos una lista:

    Por ejemplo:

    servidor = {
    "nombre": "web01",
    "ip": "192.168.1.20",
    "servicios": ["ssh", "http", "https"]
}
    • "nombre" contiene una cadena;
    • "ip" contiene una cadena;
    • "servicios" contiene una lista.

    Esto resulta útil cuando un elemento puede tener varios valores relacionados. En este caso, un servidor puede tener varios servicios activos.

    Uan vez definido el diccionario podría mostar sus dos primeros valores

    print("Servidor:", servidor["nombre"])
print("IP:", servidor["ip"])

    Y para el tercer valor se recorre la lista cuyo identificador es servidor["servicios"]

    # print(servidor["servicios"])
print("Servicios:")
for servicio in servidor["servicios"]:
    print(" -", servicio)

    Al ser una lista, para acceder a un element ose usa la notación de corchetes tras el nombre de la lista servidor["servicios"][indice]

    # Imprime un servicio de la lista
print("Primer servicio:", servidor["servicios"][0])

    Lectura de izquierda a derecha

    Esta expresión:

    servidor["servicios"][0]

    puede interpretarse como:

    1. busca la clave "servicios";
    2. obtiene la lista asociada;
    3. accede al elemento situado en la posición 0.

    También puede utilizar los métodos habituales de las listas. En este caso se añade un servicio con append: No está creando una nueva clave sino modificando la lista: 

    servidor["servicios"].append("ftp")

print("Servicios tras añadir ftp:")
for servicio in servidor["servicios"]:
    print(" -", servicio)

    2. Lista cuyos elementos son diccionarios

    El segundo caso es muy habitual. Suponga que desea guardar información sobre varios servidores.

    Puede crear una lista:

    servidores = [
    {
        "nombre": "web01",
        "ip": "192.168.1.20"
    },
    {
        "nombre": "db01",
        "ip": "192.168.1.30"
    },
    {
        "nombre": "backup01",
        "ip": "192.168.1.40"
    }
]

    En este caso tiene una lista con tres elementos. Y vada elemento es un diccionario.

    Se puede acceder al primer elemento de la lista. Ese elemento es un diccionario.

    print("Primer servidor:")
print(servidores[0])

    El resultado será:

    {
    "nombre": "web01",
    "ip": "192.168.1.20"
}

    Al ser servidores[0] un diccionario se puede acceder a sus valores:

    print("Nombre del primer servidor:")
print(servidores[0]["nombre"])
    El resultado será:

    web01

    Y para recorrer la lista mostrando los valores

    print("Lista de servidores:")
for servidor in servidores:
    print(servidor["nombre"], "=>", servidor["ip"])

    3. Anexo. Recomendaciones

    • Utilizar nombres de variables descriptivos. En estructuras combinadas es especialmente importante utilizar nombres claros. Por ejemplo:

      for servidor in servidores:

      es más fácil de entender que:

      for x in servidores:

    • Separar los pasos POR CLARIDAD. En vez de:

      print(servidores[0]["nombre"])

      puede escribir:

      primer_servidor = servidores[0]
print(primer_servidor["nombre"])
      Ambas formas son correctas, pero la segunda puede resultar más legible al principio.
